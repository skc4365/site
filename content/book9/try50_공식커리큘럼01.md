### 설치

```powershell
# 프로젝트 생성
uv init --app simple-ai-service
cd simple-ai-service

# 패키지 설치
uv add fastapi uvicorn pydantic streamlit httpx
```

### backend.py

```python
import asyncio

from fastapi import FastAPI
from pydantic import BaseModel, Field


app = FastAPI()


class Question(BaseModel):
    message: str = Field(min_length=1, max_length=200)


@app.post("/ask")
async def ask(question: Question) -> dict[str, str]:
    # 비동기 처리
    await asyncio.sleep(0.1)
    return {"answer": f"처리 결과: {question.message}"}
```

### frontend.py

```python
import httpx
import streamlit as st


st.title("AI 서비스")
message = st.text_input("질문")

if st.button("전송") and message:
    response = httpx.post(
        "http://localhost:8000/ask",
        json={"message": message},
        timeout=10,
    )
    response.raise_for_status()
    st.success(response.json()["answer"])
```

### 실행

```powershell
# 터미널 1
uv run uvicorn backend:app --reload

# 터미널 2
uv run streamlit run frontend.py
```
