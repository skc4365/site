## 완성 심플 예제

Vector 점수와 Keyword 점수 결합.

```python
from dataclasses import dataclass


@dataclass
class SearchResult:
    text: str
    vector_score: float
    keyword_score: float

    @property
    def hybrid_score(self) -> float:
        return self.vector_score * 0.7 + self.keyword_score * 0.3


def rewrite_query(question: str) -> list[str]:
    return [question, question.replace("고장", "이상 원인")]


def rerank(results: list[SearchResult]) -> list[SearchResult]:
    return sorted(results, key=lambda item: item.hybrid_score, reverse=True)


queries = rewrite_query("모터 고장")
results = [
    SearchResult("모터 진동 이상 원인", 0.92, 0.70),
    SearchResult("모터 고장 점검표", 0.78, 1.00),
]

print("검색 질문:", queries)
for result in rerank(results):
    print(round(result.hybrid_score, 3), result.text)
```

## 평가 지표

| 지표 | 질문 |
|---|---|
| Recall | 필요한 문서를 찾았는가? |

| Faithfulness | 근거 안에서 답했는가? |
| Relevance | 질문에 맞는 답인가? |
