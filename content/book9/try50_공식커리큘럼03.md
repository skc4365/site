# 공식 커리큘럼 03 · LangChain과 RAG

## 한눈에 보기

```text
문서 → Chunking → Embedding → Vector DB
                              ↓
질문 → Embedding → 유사도 검색 → Prompt → LLM → 답변
```

<p style="color:#d32f2f; font-weight:700;">RAG = 검색 근거 + LLM 생성</p>

## 학습 내용

- LangChain LCEL
- 임베딩 모델
- Chunk 크기·겹침
- Chroma·FAISS
- RAG 파이프라인

## 완성 심플 예제

외부 API 없이 LCEL 흐름 확인.

```python
from langchain_core.runnables import RunnableLambda


DOCUMENTS = [
    "프레스 설비는 매일 진동을 점검한다.",
    "컨베이어는 주 1회 벨트 장력을 확인한다.",
]


def retrieve(question: str) -> dict[str, str]:
    # 단순 키워드 검색
    document = next((doc for doc in DOCUMENTS if question[:2] in doc), DOCUMENTS[0])
    return {"question": question, "context": document}


def answer(data: dict[str, str]) -> str:
    # LLM 연결 위치
    return f"근거: {data['context']}\n답변: 근거 문서를 확인하세요."


chain = RunnableLambda(retrieve) | RunnableLambda(answer)
print(chain.invoke("프레스 점검 방법"))
```

### 실행

```powershell
# LangChain 설치
uv add langchain-core

# 예제 실행
uv run python main.py
```

실제 RAG 전환:

```text
키워드 검색 → Embedding + Vector Store
고정 답변    → Prompt + LLM API
```
