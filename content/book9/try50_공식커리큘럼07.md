## 완성 심플 예제

```text
입력 → Use Case → Repository 인터페이스 → 외부 구현
          ↑
        Test
```

`service.py`:

```python
from typing import Protocol


class TextModel(Protocol):
    def generate(self, prompt: str) -> str: ...


class SummaryService:
    def __init__(self, model: TextModel) -> None:
        self.model = model

    def summarize(self, text: str) -> str:
        if not text.strip():
            raise ValueError("빈 문서")
        return self.model.generate(f"요약: {text}")
```

`test_service.py`:

```python
import pytest

from service import SummaryService


class FakeModel:
    def generate(self, prompt: str) -> str:
        return "테스트 요약"


def test_summary() -> None:
    service = SummaryService(FakeModel())
    assert service.summarize("설비 문서") == "테스트 요약"


def test_empty_text() -> None:
    service = SummaryService(FakeModel())
    with pytest.raises(ValueError):
        service.summarize(" ")
```

### 실행

```powershell
# 테스트 도구 설치
uv add --dev pytest ruff

# 검사·테스트
uv run ruff check .
uv run pytest
```

### GitHub 협업

```powershell
# 작업 브랜치
git switch -c feature/summary-service

# 변경 저장
git add service.py test_service.py
git commit -m "feat: add summary service"

# 원격 공유
git push -u origin feature/summary-service
```
