## 한눈에 보기

```text
State
  ↓
Node A ──조건──→ Node B
  ↑               │
  └──── 순환 ─────┘
        ↓
   HITL 승인 → 종료
```

## 완성 심플 예제

조건에 따라 한 번 재시도하는 그래프.

```python
from typing import TypedDict

from langgraph.graph import END, START, StateGraph


class State(TypedDict):
    value: int
    attempts: int


def increase(state: State) -> State:
    return {
        "value": state["value"] + 1,
        "attempts": state["attempts"] + 1,
    }


def route(state: State) -> str:
    return "retry" if state["value"] < 2 else "done"


builder = StateGraph(State)
builder.add_node("increase", increase)
builder.add_edge(START, "increase")
builder.add_conditional_edges(
    "increase",
    route,
    {"retry": "increase", "done": END},
)

graph = builder.compile()
print(graph.invoke({"value": 0, "attempts": 0}))
```

### 실행

```powershell
# LangGraph 설치
uv add langgraph

# 예제 실행
uv run python main.py
```

## 확장 위치

```text
increase → LLM·Tool Node
route    → 품질·승인 조건
State    → 메시지·결과·오류
END      → 최종 응답
```

## 기억 공식

```text
상태 저장 → 노드 실행 → 조건 판단 → 다음 노드
```
