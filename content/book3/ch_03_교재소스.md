## 싱글 에이전트 원본

`CHAP6_single-agent/coding_agent/agent.py`:

```python
from langchain.agents import create_agent
from langchain_openai import ChatOpenAI

from tools import file_write_tool, python_exec_tool

llm = ChatOpenAI(model="gpt-4o")
graph = create_agent(
    model=llm,
    tools=[python_exec_tool, file_write_tool],
)
```

한 Agent가 두 도구를 선택합니다.

## 멀티 에이전트 원본

`CHAP7_multi-agent/network_agent/make_graph.py`:

```python
from langgraph.graph import MessagesState, START, StateGraph

from network_agent.chart_agent import html_node
from network_agent.research_agent import research_node

builder = StateGraph(MessagesState)
builder.add_node("researcher", research_node)
builder.add_node("html_generator", html_node)
builder.add_edge(START, "researcher")

graph = builder.compile()
```

각 노드는 내부에서 별도의 Agent를 실행하며 `Command`로 다음 역할을 정합니다.

```python
return Command(
    update={"messages": result["messages"]},
    goto="html_generator",
)
```

## 구조 차이

| 항목 | Chapter 6 | Chapter 7 |
|---|---|---|
| Agent 수 | 하나 | 여러 개 |
| 도구 제공 | 한 Agent에 도구 목록 | 역할마다 다른 도구 |
| 이동 제어 | create_agent 내부 또는 graph edge | `Command`, supervisor, handoff |
| 상태 | 한 그래프 상태 | 공유 메시지와 역할별 결과 |

## Python 3.12·LangChain 1.x 확인점

- `create_agent`는 LangChain 1.x 방식입니다.
- 동적 이동은 `langgraph.types.Command`를 사용합니다.
- 병렬 전달은 `langgraph.types.Send`를 사용할 수 있습니다.
- 복잡한 멀티 Agent를 만들기 전에 싱글 기준선을 실행해야 합니다.
