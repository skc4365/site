## 1. 단기 메모리

### Checkpointer 연결

```python
from langgraph.checkpoint.memory import InMemorySaver
from langgraph.graph import StateGraph

builder = StateGraph(Annotated[int, add])
builder.add_node("get_one", lambda value: 1)
builder.set_entry_point("get_one")
builder.set_finish_point("get_one")

graph = builder.compile(checkpointer=InMemorySaver())
```

같은 `thread_id`로 호출하면 이전 상태에 reducer 결과가 누적됩니다.

```python
config = {"configurable": {"thread_id": "user1"}}
graph.invoke(0, config)
graph.invoke(0, config)
```

### 대화 기억

```python
from langgraph.graph import MessagesState

def chatbot(state: MessagesState):
    return {"messages": [llm.invoke(state["messages"])]}

graph = builder.compile(checkpointer=InMemorySaver())
```

### 메시지 관리

원본 노트북은 세 방법을 보여줍니다.

- `trim_messages`: 최근 메시지를 토큰 한도에 맞게 전달
- `RemoveMessage`: 오래된 메시지를 상태에서 삭제
- 요약 Node: 오래된 대화를 요약한 후 일부 원문 삭제

상태 확인 API:

```python
graph.get_state(config)
list(graph.get_state_history(config))
checkpointer.delete_thread("1")
```

## 2. 장기 메모리

### Store 생성

```python
from langchain.embeddings import init_embeddings
from langgraph.store.memory import InMemoryStore

embeddings = init_embeddings("openai:text-embedding-3-small")
store = InMemoryStore(index={"embed": embeddings, "dims": 1536})
```

### Namespace와 Item 저장

```python
store.put(
    ("users",),
    "user_123",
    {"user_name": "mina", "user_age": 25},
)
```

### Tool에서 Store 접근

```python
from langgraph.config import get_store

@tool
def get_user_info(config: RunnableConfig) -> str:
    store = get_store()
    user_id = config["configurable"]["user_id"]
    item = store.get(("users",), user_id)
    return str(item.value) if item else "알 수 없는 사용자"
```

Agent에 `store`와 `checkpointer`를 동시에 전달할 수 있습니다.

```python
agent = create_agent(
    model=model,
    tools=[get_user_info, save_user_info, search_user_memories],
    store=store,
    checkpointer=InMemorySaver(),
)
```

## Python 3.12·LangChain 1.x 확인점

- checkpointer는 thread 상태, store는 thread 밖의 장기 데이터입니다.
- `InMemorySaver`와 `InMemoryStore`는 프로세스 종료 후 사라지는 학습용 구현입니다.
- `user_id`와 `thread_id`는 서로 다른 식별자입니다.
- 메시지 import는 `langchain_core.messages` 공개 경로를 우선합니다.
- 장기 검색에 임베딩을 쓰면 model과 dims가 맞아야 합니다.
