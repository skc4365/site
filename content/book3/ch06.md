# 싱글 에이전트 구현하기

## 먼저 보는 구조

```text
사용자 질문
   ↓
싱글 Agent
   ├→ 날짜 도구
   ├→ 계산 도구
   └→ 검색 도구
   ↓
최종 답변
```

> 한 Agent가 여러 도구 중 필요한 것을 선택하면 싱글 에이전트입니다.

## 기본 코드 모양

```python
from langchain.agents import create_agent
from langchain.tools import tool


@tool
def add(left: int, right: int) -> int:
    """두 정수를 더합니다."""
    return left + right


agent = create_agent(model=model, tools=[add])
```

도구의 이름, 타입 힌트, 설명문은 LLM이 도구를 선택할 때 사용하는 안내서입니다.

## Try — 도구 함수부터 시험하기

Agent에 연결하기 전에 일반 함수로 먼저 확인합니다.

```python
def word_count(text: str) -> int:
    return len(text.split())


assert word_count("agents use tools") == 3
print("도구 단위 테스트 통과")
```

그다음 `@tool`을 붙여 Agent에 전달합니다.

## 실행 흐름

```text
1. LLM이 도구 호출 이름과 입력을 생성
2. Agent 실행기가 올바른 도구를 찾음
3. Python 함수가 결과를 반환
4. LLM이 결과를 문장으로 설명
```

## 도구 설계 원칙

- 한 도구는 한 가지 작업만 수행합니다.
- 입력 타입과 설명을 구체적으로 작성합니다.
- 위험한 쓰기 작업은 승인 단계를 둡니다.
- 시간 제한과 오류 메시지를 준비합니다.

## 바로 실행하는 심플 예제

먼저 도구 함수를 단독 실행해 입력과 출력부터 확인합니다. 외부 패키지나 API 키가 필요 없습니다.

```python
def multiply(a: int, b: int) -> int:
    """두 정수를 곱합니다."""
    if not isinstance(a, int) or not isinstance(b, int):
        raise TypeError("a와 b는 정수여야 합니다.")
    return a * b


def run_agent(user_input: str) -> str:
    # 실제 Agent에서는 LLM이 도구와 인수를 선택합니다.
    if user_input == "6과 7을 곱해 줘":
        return f"도구 실행 결과: {multiply(6, 7)}"
    return "사용할 도구를 찾지 못했습니다."


print(run_agent("6과 7을 곱해 줘"))
```

결과가 `도구 실행 결과: 42`이면 도구를 Agent에 연결하기 전의 기본 검증이 끝난 것입니다.

## 기억할 내용

1. Agent보다 도구 함수를 먼저 시험한다.
2. 도구 설명은 짧고 명확하게 작성한다.
3. 단순한 문제는 싱글 Agent로 충분하다.
