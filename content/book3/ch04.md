# Python 3.12 개발 환경 준비

## 먼저 보는 구조

```text
Python 3.12
   ↓
가상환경 .venv
   ↓
고정된 패키지 버전
   ↓
.env의 API 키
   ↓
같은 명령으로 실행
```

> 환경이 같아야 강사와 교육생의 코드도 같은 방식으로 실행됩니다.

## 준비 순서

```powershell
py -3.12 -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

정상 확인:

```powershell
python --version
python -c "import langchain; print(langchain.__version__)"
```

## API 키 분리하기

`.env`:

```text
OPENAI_API_KEY=실제_API_키
OPENAI_MODEL=gpt-4.1-mini
```

Python:

```python
import os
from dotenv import load_dotenv

load_dotenv()

if not os.getenv("OPENAI_API_KEY"):
    raise RuntimeError("OPENAI_API_KEY를 확인하세요.")
```

API 키는 코드, 화면 캡처, Git 저장소에 넣지 않습니다.

## Try — 환경만 먼저 확인하기

```python
import platform

print("Python:", platform.python_version())

major, minor, *_ = platform.python_version_tuple()
if (major, minor) != ("3", "12"):
    raise RuntimeError("Python 3.12 환경에서 실행하세요.")

print("환경 확인 완료")
```

## 자주 만나는 문제

| 증상 | 먼저 확인할 것 |
|---|---|
| 모듈을 찾지 못함 | 가상환경 활성화 여부 |
| API 키 오류 | `.env` 위치와 변수 이름 |
| 강사 PC에서만 실행됨 | 패키지 버전 고정 여부 |
| 다른 Python이 실행됨 | `python --version` 결과 |

## 바로 실행하는 심플 예제

아래 파일을 실행하면 현재 Python과 API 키 설정 상태를 한 번에 점검합니다.

```python
import os
import platform
import sys


print("Python:", platform.python_version())
print("실행 파일:", sys.executable)
print("가상환경:", os.environ.get("VIRTUAL_ENV", "사용하지 않음"))
print("OPENAI_API_KEY:", "설정됨" if os.getenv("OPENAI_API_KEY") else "설정되지 않음")

if sys.version_info[:2] == (3, 12):
    print("권장 Python 3.12 환경입니다.")
else:
    print("이 교재는 Python 3.12 사용을 권장합니다.")
```

오류가 생기면 먼저 출력된 Python 실행 파일과 가상환경 경로가 예상과 같은지 확인합니다.

## 기억할 내용

1. Python 3.12와 가상환경을 먼저 확인한다.
2. 의존성 설치 기준은 하나만 사용한다.
3. 비밀값은 `.env`로 분리한다.

## 원리와 아키텍처 학습 링크

- [Python virtual environments](https://docs.python.org/3/library/venv.html) — 프로젝트별 Python 실행 환경과 패키지를 격리하는 원리를 학습합니다.
- [Python Packaging: installing packages](https://packaging.python.org/en/latest/tutorials/installing-packages/) — Python 인터프리터, 가상환경, pip가 의존성을 설치하는 관계를 확인합니다.
- [Twelve-Factor config](https://12factor.net/config) — 배포마다 달라지는 설정과 비밀값을 코드에서 분리하는 애플리케이션 원칙을 봅니다.
