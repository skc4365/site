# Python 3.12 개발 환경 준비

## 먼저 보는 구조

```text
Python 3.12
   ↓
가상환경 .venv
   ↓
고정된 패키지 버전
   ↓
.env의 API 키
   ↓
같은 명령으로 실행
```

> 환경이 같아야 강사와 교육생의 코드도 같은 방식으로 실행됩니다.

## 준비 순서

```powershell
py -3.12 -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

정상 확인:

```powershell
python --version
python -c "import langchain; print(langchain.__version__)"
```

## API 키 분리하기

`.env`:

```text
OPENAI_API_KEY=실제_API_키
OPENAI_MODEL=gpt-4.1-mini
```

Python:

```python
import os
from dotenv import load_dotenv

load_dotenv()

if not os.getenv("OPENAI_API_KEY"):
    raise RuntimeError("OPENAI_API_KEY를 확인하세요.")
```

API 키는 코드, 화면 캡처, Git 저장소에 넣지 않습니다.

## Try — 환경만 먼저 확인하기

```python
import platform

print("Python:", platform.python_version())

major, minor, *_ = platform.python_version_tuple()
if (major, minor) != ("3", "12"):
    raise RuntimeError("Python 3.12 환경에서 실행하세요.")

print("환경 확인 완료")
```

## 자주 만나는 문제

| 증상 | 먼저 확인할 것 |
|---|---|
| 모듈을 찾지 못함 | 가상환경 활성화 여부 |
| API 키 오류 | `.env` 위치와 변수 이름 |
| 강사 PC에서만 실행됨 | 패키지 버전 고정 여부 |
| 다른 Python이 실행됨 | `python --version` 결과 |

## 기억할 내용

1. Python 3.12와 가상환경을 먼저 확인한다.
2. 의존성 설치 기준은 하나만 사용한다.
3. 비밀값은 `.env`로 분리한다.
