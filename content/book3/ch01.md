# AI 에이전트, 가장 쉽게 이해하기

## 먼저 보는 구조

```text
사용자 요청
    ↓
LLM이 할 일 선택
    ↓
도구가 실제 작업 수행
    ↓
결과를 확인하고 답변
```

> LLM은 **판단하고 설명**하며, 도구는 **조회하고 계산하고 저장**합니다.

## LLM과 에이전트의 차이

### LLM 호출

질문을 받아 답변을 한 번 생성합니다.

```text
질문 → LLM → 답변
```

### AI 에이전트

목표를 받은 뒤 필요한 기능을 선택하고 결과를 확인합니다.

```text
목표 → LLM → 도구 선택 → 실행 결과 → 최종 답변
```

| 구성요소 | 쉬운 뜻 | 예시 |
|---|---|---|
| LLM | 무엇을 할지 판단 | 계산 도구 선택 |
| 도구 | 실제 작업 수행 | 더하기, 검색, 파일 읽기 |
| 상태 | 작업 중인 내용 기억 | 질문, 도구 결과 |
| 흐름 | 다음 순서 결정 | 도구 실행 후 답변 |

## Try 1 — 에이전트 흐름 직접 보기

다음 코드는 외부 패키지와 API 키 없이 실행할 수 있습니다.

```python
def add(left: int, right: int) -> int:
    """실제 계산을 담당하는 도구"""
    return left + right


def choose_action(user_input: str) -> str:
    """LLM의 도구 선택을 단순한 규칙으로 표현"""
    if "더" in user_input:
        return "add"
    return "answer"


question = "17과 25를 더해 줘"
action = choose_action(question)

if action == "add":
    tool_result = add(17, 25)
    answer = f"계산 결과는 {tool_result}입니다."
else:
    answer = "도구를 사용하지 않고 답변합니다."

print("선택한 행동:", action)
print("최종 답변:", answer)
```

예상 결과:

```text
선택한 행동: add
최종 답변: 계산 결과는 42입니다.
```

여기서는 규칙이 행동을 골랐습니다. 실제 에이전트에서는 LLM이 사용자 문장을 이해하고 적절한 도구를 선택합니다.

## 바로 실행하는 심플 예제

LLM의 판단과 실제 도구 실행이 서로 다른 단계라는 것을 확인하는 최소 예제입니다.

```python
def choose_action(user_input: str) -> str:
    """실제로는 이 판단을 LLM이 수행합니다."""
    return "calculator" if any(char.isdigit() for char in user_input) else "answer"


def calculator(a: int, b: int) -> int:
    return a + b


question = "20과 22를 더해 줘"
action = choose_action(question)

if action == "calculator":
    result = calculator(20, 22)
    print(f"선택한 작업: {action}")
    print(f"최종 답변: {result}")
else:
    print("도구 없이 답변합니다.")
```

실행 결과는 `선택한 작업: calculator`, `최종 답변: 42`입니다.

## 기억할 내용

1. LLM은 실제 작업을 직접 하지 않는다.
2. 도구가 외부 데이터와 프로그램을 다룬다.
3. 에이전트는 LLM·도구·상태·흐름을 연결한 시스템이다.
