# 에이전트의 세 가지 핵심

## 먼저 보는 구조

```text
추론: 무엇을 할까?
  ↓
도구: 실제로 실행
  ↓
메모리: 다음 판단에 필요한 내용을 기억
```

> 에이전트는 **생각만 하는 LLM**이 아니라, 판단·실행·기억이 연결된 프로그램입니다.

## 쉽게 구분하기

| 요소 | 하는 일 | 하지 말아야 할 일 |
|---|---|---|
| 추론 | 요청 이해, 도구 선택 | 정확한 계산을 짐작하기 |
| 도구 | 계산, 검색, 파일 처리 | 검증 없이 위험한 작업 수행 |
| 메모리 | 대화와 중간 결과 보관 | 모든 내용을 영구 저장하기 |

## Try — 도구를 선택하는 흐름

```python
def calculator(expression: str) -> int:
    numbers = [int(value) for value in expression.split("+")]
    return sum(numbers)


question = "12+30을 계산해 줘"

if "+" in question:
    result = calculator("12+30")
    answer = f"도구 실행 결과: {result}"
else:
    answer = "도구가 필요하지 않습니다."

print(answer)
```

```text
도구 실행 결과: 42
```

실제 LangChain Agent에서는 LLM이 도구 설명을 읽고 필요한 도구를 선택합니다.

## 판단 흐름 읽기

```text
사용자 질문
  → LLM이 도구 호출 요청 생성
  → Python이 입력값 검사
  → 도구 실행
  → 실행 결과를 LLM에 전달
  → 최종 답변
```

도구 호출 요청과 도구 실행은 다릅니다. LLM은 요청하고, 애플리케이션 코드가 실행합니다.

## 바로 실행하는 심플 예제

추론(선택), 도구(실행), 메모리(저장)를 한 번에 확인합니다.

```python
memory: dict[str, int] = {}


def add(a: int, b: int) -> int:
    return a + b


def run_agent(a: int, b: int) -> str:
    selected_tool = "add"  # 추론: 어떤 도구를 쓸지 선택
    result = add(a, b)      # 도구: 실제 계산 실행
    memory["last_result"] = result  # 메모리: 결과 저장
    return f"{selected_tool} 실행 결과: {result}"


print(run_agent(20, 22))
print("저장된 값:", memory["last_result"])
```

실행 결과에서 계산값 `42`가 메모리에도 저장된 것을 확인할 수 있습니다.

## 기억할 내용

1. 추론은 선택, 도구는 실행이다.
2. 도구 입력은 실행 전에 검사한다.
3. 메모리는 목적과 보관 기간을 정해서 사용한다.
