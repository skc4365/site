# LangGraph로 작업 흐름 만들기

## 먼저 보는 구조

```text
START → 질문 확인 → 답변 작성 → 결과 검사 → END
```

> LangGraph는 작업의 상태와 이동 순서를 코드로 명확하게 표현합니다.

## 네 가지 기본 요소

| 요소 | 뜻 |
|---|---|
| State | 노드들이 함께 사용하는 데이터 |
| Node | 한 단계의 작업 함수 |
| Edge | 다음 노드로 이동하는 연결 |
| Conditional Edge | 상태에 따라 달라지는 분기 |

## Try — 가장 작은 그래프

```python
from typing import TypedDict

from langgraph.graph import END, START, StateGraph


class State(TypedDict):
    number: int
    result: int


def double(state: State) -> dict:
    return {"result": state["number"] * 2}


builder = StateGraph(State)
builder.add_node("double", double)
builder.add_edge(START, "double")
builder.add_edge("double", END)

graph = builder.compile()
print(graph.invoke({"number": 21, "result": 0}))
```

```text
{'number': 21, 'result': 42}
```

## 상태가 변하는 과정

```text
입력 상태   {number: 21, result: 0}
                    ↓ double 노드
출력 상태   {number: 21, result: 42}
```

노드는 전체 상태를 새로 만들기보다 자신이 변경할 값만 반환합니다.

## 좋은 그래프의 기준

- 노드 하나가 한 가지 일만 한다.
- 모든 분기에 종료 경로가 있다.
- 상태 필드의 의미가 분명하다.
- 실패와 재시도 횟수를 제한한다.

## 기억할 내용

1. State는 흐르는 데이터다.
2. Node는 작업, Edge는 순서다.
3. 그래프는 `compile()`한 뒤 `invoke()`한다.
