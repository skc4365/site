## 도구 바인딩 원본 흐름

`web_agent/agent.py`는 Tavily 검색 기능을 모델에 연결합니다.

```python
from langchain_openai import ChatOpenAI
from langchain_tavily import TavilySearch

tool = TavilySearch(max_results=3)
tools = [tool]

llm = ChatOpenAI(model="gpt-4o")
llm_with_tools = llm.bind_tools(tools)
```

모델이 반환한 `AIMessage.tool_calls`를 실행한 뒤 `ToolMessage`로 결과를 돌려줍니다.

```python
from langchain_core.messages import ToolMessage

tool_result = tool.invoke(tool_call["args"])
tool_message = ToolMessage(
    content=str(tool_result),
    name=tool_call["name"],
    tool_call_id=tool_call["id"],
)
```

## create_agent 방식

LangChain 1.x에서는 표준적인 모델↔도구 반복을 `create_agent`로 만들 수 있습니다.

```python
from langchain.agents import create_agent
from langchain_openai import ChatOpenAI

agent = create_agent(
    model=ChatOpenAI(model="gpt-4o"),
    tools=[tool],
)
```

## 단기 메모리 원본 흐름

```python
from langgraph.checkpoint.memory import InMemorySaver

agent = create_agent(
    model=model,
    tools=[tool],
    checkpointer=InMemorySaver(),
)

config = {"configurable": {"thread_id": "1"}}
```

같은 `thread_id`를 사용한 호출은 같은 대화 상태를 이어갑니다.

## 장기 메모리 원본 흐름

```python
from langgraph.store.memory import InMemoryStore

store = InMemoryStore()
store.put(
    ("users",),
    "user_123",
    {"user_name": "mina", "user_age": 25},
)
```

## Python 3.12·LangChain 1.x 확인점

- 메시지는 `langchain_core.messages` 또는 LangChain 1.x 공개 경로를 사용합니다.
- Agent 생성은 `langchain.agents.create_agent`를 사용합니다.
- 단기 상태는 checkpointer, 장기 데이터는 store로 분리합니다.
- `AgentExecutor` 중심의 구형 0.x 튜토리얼과 섞지 않습니다.
