## `4.4_main.py` 흐름

```python
from dotenv import load_dotenv
from langchain_openai import ChatOpenAI

load_dotenv()

llm = ChatOpenAI(model="gpt-4o")

messages = [
    (
        "system",
        "당신은 사용자가 한 말을 영어로 번역하는 유능한 번역가입니다.",
    ),
    ("human", "안녕하세요."),
]

ai_msg = llm.invoke(messages)
print(ai_msg)
```

## 한 줄씩 읽기

1. `load_dotenv()`가 `.env`의 값을 현재 프로세스로 읽습니다.
2. `ChatOpenAI`는 OpenAI Chat Model을 LangChain 인터페이스로 감쌉니다.
3. `messages`는 역할과 내용의 목록입니다.
4. `invoke()`는 동기 호출이며 `AIMessage`를 반환합니다.
5. 실제 문자열은 `ai_msg.content`에서 읽습니다.

## 안전한 확인 코드

import os

## 원본 환경에서 주의할 점

- README의 Conda 명령 예시에는 `Scipts` 오타가 있으므로 실제 경로는 `Scripts`인지 확인합니다.
- `uv.lock`과 `requirements.txt`를 동시에 기준으로 설치하지 않습니다.
- 저장소의 requirements에는 Windows 전용 패키지와 선택 서비스가 포함되어 있습니다.
- 첫 실습은 최소 패키지만 설치하는 환경과 원본 전체 재현환경을 분리하는 편이 안전합니다.
