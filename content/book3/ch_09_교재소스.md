## 1. FastMCP 서버

`mcp_agent/server.py`는 tool 두 개와 prompt 하나를 등록합니다.

```python
from mcp.server.fastmcp import FastMCP

mcp = FastMCP("MCPServer")


@mcp.tool()
def read_user_info() -> str:
    """사용자 정보를 담은 텍스트 파일을 읽습니다."""
    ...


@mcp.tool()
def save_diary(
    conversation_summary: str,
    emotion: str,
    resolution: str,
) -> dict:
    """대화 내용을 일기 파일로 저장합니다."""
    ...


if __name__ == "__main__":
    mcp.run(transport="stdio")
```

Prompt 등록:

```python
from mcp.server.fastmcp.prompts import base


@mcp.prompt()
def default_prompt(message: str) -> list[base.Message]:
    return [
        base.AssistantMessage("당신은 개인 비서입니다."),
        base.UserMessage(message),
    ]
```

## 2. stdio Client

`mcp_agent/client.py`는 서버 프로세스를 시작하고 ClientSession을 초기화합니다.

```python
import sys

from mcp import ClientSession, StdioServerParameters
from mcp.client.stdio import stdio_client

params = StdioServerParameters(
    command=sys.executable,
    args=["./server.py"],
)

async with stdio_client(params) as (read, write):
    async with ClientSession(read, write) as session:
        await session.initialize()
```

원본은 `command="python"`을 사용하지만, Python 3.12 가상환경을 확실하게 유지하려면 `sys.executable`이 안전합니다.

## 3. MCP Tool을 LangChain Agent에 연결

```python
from langchain.agents import create_agent
from langchain_mcp_adapters.prompts import load_mcp_prompt
from langchain_mcp_adapters.tools import load_mcp_tools

tools = await load_mcp_tools(session)
prompts = await load_mcp_prompt(
    session,
    "default_prompt",
    arguments={"message": user_input},
)

agent = create_agent(model, tools, checkpointer=InMemorySaver())
result = await agent.ainvoke(
    {"messages": prompts},
    config={"configurable": {"user_id": "user_123", "thread_id": "1"}},
)
```

## 4. MultiServerMCPClient

`mcp_multi_agent/client.py`는 원격 Tavily 서버와 로컬 파일 서버를 함께 연결합니다.

```python
from langchain_mcp_adapters.client import MultiServerMCPClient

client = MultiServerMCPClient(
    {
        "tavily": {
            "url": "https://mcp.tavily.com/mcp/",
            "transport": "streamable_http",
        },
        "file": {
            "transport": "stdio",
            "command": sys.executable,
            "args": ["./server.py"],
        },
    }
)
```

서버별 도구 조회:

```python
all_tools = await client.get_tools()
tavily_tools = await client.get_tools(server_name="tavily")
file_tools = await client.get_tools(server_name="file")
```

## 5. Supervisor Graph

원본은 파일 도구 Agent와 웹 도구 Agent를 만들고 supervisor가 다음 역할을 선택합니다.

```text
START → supervisor
           ├→ file_searcher → supervisor
           ├→ web_searcher  → supervisor
           └→ END
```

## Python 3.12·LangChain 1.x 확인점

- Agent는 `langchain.agents.create_agent`를 사용합니다.
- MCP 변환은 `langchain-mcp-adapters`를 사용합니다.
- Windows stdio는 event loop 정책과 실행기 경로를 확인합니다.
- URL query string에 API 키를 넣으면 로그에 노출될 수 있으므로 실제 서비스에서는 인증 방식을 다시 설계합니다.
- `asyncio.run()`은 파일 진입점에서 한 번만 호출합니다.
