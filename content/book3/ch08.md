# 에이전트 메모리 이해하기

## 먼저 보는 구조

```text
현재 대화 ─→ 단기 메모리 ─→ 같은 대화에서 사용

사용자 정보 ─→ 장기 메모리 ─→ 다음 대화에서도 사용
```

> 단기 메모리는 대화의 흐름을, 장기 메모리는 다시 사용할 정보를 보관합니다.

## 두 메모리 비교

| 구분 | 단기 메모리 | 장기 메모리 |
|---|---|---|
| 범위 | 하나의 대화 | 여러 대화 |
| 키 | `thread_id` | 사용자·항목 식별자 |
| 내용 | 메시지와 중간 상태 | 선호, 프로필, 지식 |
| 주의 | 대화가 계속 길어짐 | 삭제·동의·보관 정책 필요 |

## Try — 대화별 기억 분리하기

```python
memory: dict[str, list[str]] = {}


def remember(thread_id: str, message: str) -> None:
    memory.setdefault(thread_id, []).append(message)


remember("student-01", "내 별명은 코딩곰이야")
remember("student-02", "내 별명은 파이썬새야")

print(memory["student-01"])
print(memory["student-02"])
```

`thread_id`가 다르면 대화 기록도 분리됩니다. LangGraph의 Checkpointer가 이 역할을 담당합니다.

## LangGraph 연결 모양

```python
from langgraph.checkpoint.memory import InMemorySaver

checkpointer = InMemorySaver()
graph = builder.compile(checkpointer=checkpointer)

config = {"configurable": {"thread_id": "student-01"}}
result = graph.invoke(input_state, config=config)
```

`InMemorySaver`는 프로그램을 종료하면 내용이 사라지는 학습용 저장소입니다.

## 저장 전에 물어볼 것

- 꼭 기억해야 하는 정보인가?
- 언제 삭제할 것인가?
- 다른 사용자의 정보와 분리되는가?
- 민감한 원문을 저장하고 있지 않은가?

## 바로 실행하는 심플 예제

`thread_id`별로 대화를 분리해서 저장하는 최소 메모리 예제입니다.

```python
conversation_store: dict[str, list[str]] = {}


def remember(thread_id: str, message: str) -> None:
    conversation_store.setdefault(thread_id, []).append(message)


def recall(thread_id: str) -> list[str]:
    return conversation_store.get(thread_id, [])


remember("student-a", "관심 주제는 RAG")
remember("student-a", "다음에는 평가를 학습")
remember("student-b", "관심 주제는 MCP")

print("student-a:", recall("student-a"))
print("student-b:", recall("student-b"))
```

출력에서 두 사용자의 기록이 섞이지 않으면 `thread_id` 분리가 제대로 동작한 것입니다.

## 기억할 내용

1. 단기와 장기 메모리는 목적이 다르다.
2. 대화는 `thread_id`로 분리한다.
3. 필요한 정보만 정해진 기간 동안 저장한다.
