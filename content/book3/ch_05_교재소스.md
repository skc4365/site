## 5.2 소스 흐름

### State 정의

```python
from typing import Annotated
from typing_extensions import TypedDict


def add(left, right):
    return left + right


class State(TypedDict):
    messages: Annotated[list[str], add]
```

`Annotated`의 두 번째 값은 새 상태를 기존 상태와 어떻게 합칠지 정하는 reducer입니다.

메시지 객체에는 LangGraph의 `add_messages`를 사용합니다.

```python
from langchain_core.messages import AnyMessage
from langgraph.graph.message import add_messages


class State(TypedDict):
    messages: Annotated[list[AnyMessage], add_messages]
```

### Node와 Edge

```python
from langgraph.graph import END, START, StateGraph


def chatbot(state: State):
    question = state["messages"]
    return {"messages": [f"질문을 받았습니다: {question}"]}


builder = StateGraph(State)
builder.add_node("chatbot", chatbot)
builder.add_edge(START, "chatbot")
builder.add_edge("chatbot", END)

graph = builder.compile()
```

## 5.3 입력·출력 스키마

```python
class InputState(TypedDict):
    question: str


class OutputState(TypedDict):
    answer: str


class OverallState(TypedDict):
    question: str
    answer: str
    messages: Annotated[list[str], add]


builder = StateGraph(
    OverallState,
    input_schema=InputState,
    output_schema=OutputState,
)
```

외부에는 `question`만 받고 `answer`만 보여주면서, 내부에서는 `messages`를 추가로 사용할 수 있습니다.

## 조건부 Edge

원본은 질문 길이를 확인해 다음 노드를 선택합니다.

```python
def route(state: State):
    if state["question_length"] > 3:
        return "chatbot"
    return END


builder.add_conditional_edges(
    "guardrail",
    route,
    {"chatbot": "chatbot", END: END},
)
```

## Python 3.12·LangGraph 1.x 확인점

- `StateGraph`, `START`, `END`는 `langgraph.graph`에서 가져옵니다.
- 모든 Node는 전체 State가 아니라 바뀐 필드만 반환할 수 있습니다.
- reducer가 없는 필드는 기본적으로 새 값으로 교체됩니다.
- `compile()` 이후의 graph에 `invoke`, `ainvoke`, `stream`, `astream`을 사용합니다.
