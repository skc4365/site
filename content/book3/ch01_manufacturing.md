# Chapter 01 쉬운 제조 실습 — 기계 상태 도우미 그리기

## 이번 실습에서 쓰는 쉬운 말

| 어려운 말 | 쉬운 말 | 코드 이름 |
|---|---|---|
| 설비 | 기계 | `machine` |
| 이상 징후 | 상태 알림 | `alert` |
| 생산 실적 | 만든 개수 | `made_count` |
| 불량 | 문제 제품 | `bad_count` |
| 정비 | 점검 | `check` |
| 근거 | 확인 자료 | `source` |

## 만들 것

교육 과정에서 계속 발전시킬 프로그램은 **기계 상태 도우미**입니다.

사용자 질문:

> M-01 기계에 상태 알림이 생겼어. 오늘 만든 제품과 작업 안내서를 확인해 줘.

프로그램의 첫 그림:

```text
[작업자]
   │ 질문
   ▼
[기계 상태 도우미]
   ├─ 오늘 만든 개수 확인
   ├─ 문제 제품 개수 확인
   ├─ 작업 안내서 검색
   └─ 확인한 자료와 함께 설명
```

## 중요한 약속

도우미가 해도 되는 일:

- 저장된 숫자 읽기
- 작업 안내서 찾기
- 확인된 내용을 쉬운 문장으로 설명하기

도우미가 하면 안 되는 일:

- 없는 숫자 만들기
- 고장 원인을 확정하기
- 사람 확인 없이 기계를 조작하기
- 사람 확인 없이 점검 작업 등록하기

## 손으로 그리는 실습

종이에 다음 네 개의 상자를 그립니다.

```text
[사람] → [도우미] → [기계 데이터]
                  → [작업 안내서]
```

그림에 다음 표시를 추가합니다.

1. 데이터는 읽기만 가능한가?
2. 사람이 확인해야 하는 지점은 어디인가?
3. 데이터가 없으면 어떻게 말해야 하는가?
4. 어느 자료를 확인했는지 어디에 표시할 것인가?

## 아주 작은 데이터

```python
machine_data = {
    "machine_id": "M-01",
    "made_count": 100,
    "bad_count": 3,
    "alert": "진동이 평소보다 큼",
}
```

`machine_id`는 기계 이름, `made_count`는 만든 개수, `bad_count`는 문제 제품 개수입니다.

## 말로 설명하는 연습

다음 문장을 완성합니다.

> 작업자가 질문하면 도우미는 ______와 ______를 확인합니다. 데이터가 없으면 ______라고 말합니다. 점검 작업을 저장하기 전에는 반드시 ______의 확인을 받습니다.

## 완료 기준

- [ ] 기계 상태 도우미의 역할을 한 문장으로 설명했다.
- [ ] 데이터 읽기와 기계 조작을 구분했다.
- [ ] 사람이 확인할 위치를 그림에 표시했다.
- [ ] `machine_id`, `made_count`, `bad_count`의 뜻을 안다.
