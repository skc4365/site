## 1. web_agent

`web_agent/agent.py`는 도구 호출 과정을 직접 StateGraph로 구성합니다.

```text
START → chatbot
          ├─ tool call 없음 → END
          └─ tool call 있음 → tools → chatbot
```

핵심 초기화:

```python
from langchain_openai import ChatOpenAI
from langchain_tavily import TavilySearch

tool = TavilySearch(max_results=3)
tools = [tool]

llm = ChatOpenAI(model="gpt-4o")
llm_with_tools = llm.bind_tools(tools)
```

도구 실행 노드의 핵심:

```python
from langchain_core.messages import ToolMessage

tool_result = tools_by_name[tool_call["name"]].invoke(tool_call["args"])
return ToolMessage(
    content=str(tool_result),
    name=tool_call["name"],
    tool_call_id=tool_call["id"],
)
```

원본은 `BasicToolNode`와 `route_tools()`를 직접 작성해 `bind_tools()` 내부 메시지 구조를 이해하도록 합니다.

## 2. coding_agent

`coding_agent/agent.py`는 LangChain 1.x `create_agent`를 사용합니다.

```python
from langchain.agents import create_agent
from langchain_openai import ChatOpenAI

from tools import file_write_tool, python_exec_tool

graph = create_agent(
    model=ChatOpenAI(model="gpt-4o"),
    tools=[python_exec_tool, file_write_tool],
)
```

`tools.py`는 `@tool`로 함수 schema를 만듭니다.

```python
from langchain.tools import tool
from pydantic import Field


@tool
def file_write_tool(
    file_path: str = Field(description="생성/수정할 파일의 경로"),
    content: str = Field(description="파일에 작성할 내용"),
) -> str:
    """파일을 생성하거나 내용을 작성합니다."""
    ...
```

원본 `python_exec_tool`은 `exec()`를, `file_write_tool`은 전달받은 경로 쓰기를 사용합니다. 구조 학습에는 유용하지만 교육생 PC에서 그대로 실행하기 전 별도 격리환경과 경로 제한이 필요합니다.

## 4. rag_agent

원본 파일 관계:

```text
agent.py      전체 Graph 연결
state.py      AgentState 정의
retriever.py  Chroma와 검색 Tool
nodes.py      검색·정리·질의변환·생성 Node
edges.py      생성 여부·환각 검사 분기
```

그래프 흐름:

```text
START → chatbot
          ├─ END
          └─ retriever → context_organizer
                            ├─ transform_query → retriever
                            └─ generate
                                  ├─ support → END
                                  └─ not supported → generate
```

검색 Tool:

```python
from langchain_chroma import Chroma
from langchain_core.tools import create_retriever_tool
from langchain_openai import OpenAIEmbeddings

vectorstore = Chroma(
    persist_directory="./rag_agent/chroma_db",
    embedding_function=OpenAIEmbeddings(model="text-embedding-3-small"),
    collection_name="korean_pdf",
)

retriever_tool = create_retriever_tool(
    vectorstore.as_retriever(search_kwargs={"k": 3}),
    name="pdf_search",
    description="Search the Korean Spelling Rules PDF document",
)
```

## Python 3.12·LangChain 1.x 확인점

- `create_agent`는 `langchain.agents`에서 가져옵니다.
- 메시지와 ToolMessage는 `langchain_core.messages` 공개 경로를 우선합니다.
- `tools_condition`은 `langgraph.prebuilt`에서 가져옵니다.
- 검색 그래프의 재시도 경로에는 최대 횟수를 추가해 무한 반복을 막아야 합니다.
- 원본의 상대경로는 실행 디렉터리에 따라 달라질 수 있으므로 `Path(__file__)` 기준이 안전합니다.
