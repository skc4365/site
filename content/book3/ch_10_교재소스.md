## 1. HelloWorld AgentExecutor

```python
from a2a.server.agent_execution import AgentExecutor, RequestContext
from a2a.server.events import EventQueue
from a2a.utils import new_agent_text_message


class HelloWorldAgentExecutor(AgentExecutor):
    async def execute(
        self,
        context: RequestContext,
        event_queue: EventQueue,
    ) -> None:
        result = "Hello World! 안녕하세요, A2A 에이전트입니다!"
        await event_queue.enqueue_event(new_agent_text_message(result))

    async def cancel(
        self,
        context: RequestContext,
        event_queue: EventQueue,
    ) -> None:
        raise Exception("cancel은 지원되지 않습니다")
```

Executor는 A2A 요청과 내부 Agent 사이의 adapter입니다.

## 2. Agent Card와 Server

`agent_server.py`는 Skill과 Card를 정의합니다.

```python
from a2a.types import AgentCapabilities, AgentCard, AgentSkill

skill = AgentSkill(
    id="hello_world",
    name="Hello World 인사",
    description="간단한 인사말을 반환합니다",
    tags=["인사", "hello world", "기본"],
    examples=["안녕", "hello"],
)

card = AgentCard(
    name="Hello World Agent",
    description="간단한 인사를 반환하는 예제 Agent",
    url="http://localhost:9999",
    version="1.0.0",
    default_input_modes=["text"],
    default_output_modes=["text"],
    capabilities=AgentCapabilities(streaming=False),
    skills=[skill],
)
```

이 Card를 `DefaultRequestHandler`, `InMemoryTaskStore`, `A2AStarletteApplication`과 연결하고 Uvicorn으로 실행합니다.

## 5. MCP Agent Server

`multi_agent/mcp_agent/`는 MCP 도구를 사용하는 Agent를 A2A 서비스로 공개합니다.

```text

 → 결과를 A2A Event로 반환
```

## 6. AgentOrchestrator

`agent_orchestrator.py`는 두 Agent URL에서 Card를 읽고 A2AClient를 보관합니다.

```python
card_resolver = A2ACardResolver(
    httpx_client=http_client,
    base_url=url,
)
agent_card = await card_resolver.get_agent_card()

client = A2AClient(
    httpx_client=http_client,
    agent_card=agent_card,
)
```

LLM에는 `send_message(agent_name, task)` 도구를 제공하고 최대 반복 횟수를 6으로 제한합니다.

## Python 3.12·1.x 확인점

- 이 챕터의 LangChain Agent는 1.x `create_agent` 방식입니다.
- A2A SDK API는 변경 가능성이 있으므로 제공 lock 파일 기준으로 먼저 재현합니다.
- 모든 Agent 서버를 서로 다른 포트에서 실행합니다.
- Card의 URL과 실제 서버 주소가 일치해야 합니다.
- `httpx.AsyncClient`는 작업 종료 시 닫습니다.
- timeout과 최대 반복은 원격 Agent 무한 대기를 막습니다.
