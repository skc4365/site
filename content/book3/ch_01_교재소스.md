## 가장 가까운 원본 코드

`PART2/4.4_main.py`의 흐름은 다음과 같습니다.

```python
from dotenv import load_dotenv
from langchain_openai import ChatOpenAI

load_dotenv()

llm = ChatOpenAI(model="gpt-4o")
messages = [
    ("system", "당신은 사용자가 한 말을 영어로 번역하는 번역가입니다."),
    ("human", "안녕하세요."),
]

answer = llm.invoke(messages)
print(answer)
```

이 코드는 LLM 한 번을 호출하므로 아직 에이전트는 아닙니다.

```text
메시지 → ChatOpenAI.invoke() → AIMessage
```

Chapter 6에서 도구와 반복 흐름이 추가되면 에이전트 구조가 됩니다.

## Python 3.12·LangChain 1.x 확인점

- `ChatOpenAI`는 `langchain_openai`에서 가져옵니다.
- 모델 이름 인자는 `model="..."`을 사용합니다.
- 결과는 문자열이 아니라 `AIMessage`이며 본문은 `.content`로 읽습니다.
- API 키는 코드가 아니라 `.env`의 `OPENAI_API_KEY`로 전달합니다.
