# 멀티 에이전트 구현하기

## 먼저 보는 구조

```text
사용자 요청
    ↓
Supervisor
    ├→ 조사 Agent
    ├→ 검토 Agent
    └→ 작성 Agent
    ↓
최종 결과
```

> Supervisor는 모든 일을 하지 않고, 적절한 전문 Agent에게 작업을 전달합니다.

## 역할을 나누는 기준

| 역할 | 입력 | 출력 |
|---|---|---|
| 조사 | 사용자 주제 | 확인한 핵심 정보 |
| 검토 | 조사 결과 | 문제점과 개선 의견 |
| 작성 | 자료와 검토 | 최종 답변 |

역할 이름보다 **무엇을 받고 무엇을 돌려주는지**가 중요합니다.

## Try — 간단한 Supervisor

```python
def supervisor(request: str) -> str:
    if "요약" in request:
        return "summarizer"
    return "explainer"


def summarizer(text: str) -> str:
    return f"요약 결과: {text[:12]}..."


def explainer(text: str) -> str:
    return f"쉬운 설명: {text}"


request = "멀티 에이전트를 요약해 줘"
route = supervisor(request)
result = summarizer(request) if route == "summarizer" else explainer(request)

print("선택한 Agent:", route)
print(result)
```

## Handoff 이해하기

```text
Supervisor → 다음 역할과 필요한 데이터 전달 → 전문 Agent
```

전체 대화를 무조건 전달하면 비용과 정보 노출이 커집니다. 다음 역할에 필요한 정보만 전달합니다.

## 실패를 다루는 방법

- Agent별 시간 제한을 둡니다.
- 재시도 횟수를 제한합니다.
- 일부 Agent가 실패했을 때 가능한 응답을 정합니다.
- 어느 Agent에서 실패했는지 로그에 남깁니다.

## 바로 실행하는 심플 예제

Supervisor가 요청을 분류하고 담당 Agent 하나에게 전달하는 예제입니다.

```python
def search_agent(query: str) -> str:
    return f"검색 결과: {query} 관련 문서 3건"


def calculator_agent(expression: str) -> str:
    numbers = [int(value) for value in expression.split("+")]
    return f"계산 결과: {sum(numbers)}"


def supervisor(request: str) -> str:
    if "+" in request:
        return calculator_agent(request)
    return search_agent(request)


print(supervisor("20+22"))
print(supervisor("LangGraph"))
```

Supervisor에는 조정만 맡기고, 실제 작업은 역할별 함수에서 수행합니다.

## 기억할 내용

1. 역할마다 입력과 출력을 정의한다.
2. Supervisor는 작업을 선택하고 전달한다.
3. 멀티 Agent는 조정 비용이 추가된다.
