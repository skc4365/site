| 구분 | 내용 |
|---|---|
| 교육 기간 | 6일 |
| 총 교육 시간 | 48시간 · 1일 8시간 |

## DAY 1 · Python 심화와 비동기 프로그래밍

> **학습 목표:** 동기와 비동기의 차이를 이해하고, Type Hinting과 `async`·`await`를 활용해 안정적인 비동기 코드를 작성합니다.

### 1교시 · Python 고급 문법과 Type Hinting `4h`

- `dataclasses`를 활용한 데이터 객체 정의
- `Generics`와 Type Annotation 설계
- 데코레이터의 동작 원리와 직접 구현
- Context Manager: `with`, `__enter__()`, `__exit__()`

### 2교시 · 비동기 프로그래밍 핵심 `4h`

- 이벤트 루프의 역할
- Blocking과 Non-Blocking 비교
- `async`, `await`, `asyncio.run()`
- `asyncio.gather()`를 활용한 동시 실행
- `aiofiles` 기반 비동기 파일 I/O
- `httpx` 기반 비동기 HTTP 요청

**일일 산출물:** 여러 API 요청을 동시에 처리하고 실행 시간을 비교하는 비동기 프로그램

## DAY 2 · Pydantic v2와 FastAPI 기초

> **학습 목표:** Pydantic으로 입력 데이터 검증 체계를 만들고 FastAPI의 요청·응답 구조를 익힙니다.

### 1교시 · Pydantic v2 데이터 모델링 `4h`

- `BaseModel`과 `Field`
- 기본 자료형 검증과 중첩 모델 설계
- 데이터 검증과 변환
  - `@field_validator`
  - `@model_validator`
- `pydantic-settings`와 `.env` 환경 변수 연동

### 2교시 · FastAPI 파운데이션 `4h`

- FastAPI 동작 구조: Starlette · Pydantic · ASGI
- Path Parameter와 Query Parameter
- Request Body 처리
- Swagger UI 자동 문서 `/docs`
- `HTTPException`을 활용한 오류 응답

**일일 산출물:** 요청 값을 검증하고 오류를 일관된 형식으로 반환하는 기본 REST API

## DAY 3 · FastAPI 비동기 REST API 설계

> **학습 목표:** 비동기 데이터베이스와 의존성 주입을 활용해 유지보수 가능한 API 백엔드를 구축합니다.

### 1교시 · 비동기 DB와 ORM `4h`

- SQLAlchemy 2.0 Async Engine
- SQLite와 PostgreSQL 연결
- 비동기 Session 생명주기 관리
- Create · Read · Update · Delete API 개발
- 트랜잭션 처리와 예외 대응

### 2교시 · Dependency Injection과 구조화 `4h`

- `Depends()` 기반 의존성 주입
- DB Session과 인증 Token 주입
- `APIRouter`를 활용한 도메인별 모듈 분리
- 서비스 확장을 고려한 디렉터리 구조

```text
app/
  ├─ main.py
  ├─ routers/
  ├─ schemas/
  ├─ models/
  ├─ services/
  └─ database/
```

**일일 산출물:** 계층과 책임이 분리된 비동기 CRUD API

**일일 산출물:** FastAPI 응답을 조회하고 화면에 표시하는 Streamlit 프런트엔드

## DAY 6 · 무료 배포와 CI/CD

> **학습 목표:** 개발한 서비스를 클라우드에 배포하고 환경 변수·CORS·전체 사용자 흐름을 최종 검증합니다.

### 1교시 · 프런트엔드와 백엔드 분리 배포 `4h`

| 구성 요소 | 배포 후보 | 확인 사항 |
|---|---|---|
| FastAPI 백엔드 | Render · Fly.io 등 | 실행 명령 · Port · Health Check |
| PostgreSQL | Supabase 등 | 연결 문자열 · SSL · 접근 권한 |
| Streamlit 프런트엔드 | Streamlit Community Cloud | 저장소 연결 · 시작 파일 · Secrets |

- Git 저장소와 배포 서비스 연결
- 백엔드 실행 명령과 환경 설정
- 프런트엔드에서 배포된 API 주소 사용
- 배포 로그를 통한 오류 확인

### 2교시 · 환경 변수와 최종 점검 `4h`

- `st.secrets`를 활용한 Streamlit Secrets 관리
- 배포 서비스 Environment Variables 설정
- API Key와 DB 접속 정보 보호
- 배포 환경 CORS 문제 해결
- 프런트엔드 → API → DB 전체 E2E 테스트
- 최종 시연과 개선 사항 정리

**일일 산출물:** 인터넷에서 접속할 수 있는 최종 웹 서비스

- [ ] 프런트엔드와 백엔드가 배포 환경에서 통신한다.
