# 첫 만남: 완성된 AI 서비스부터 출발하기

> 오늘의 목표는 모든 문법을 외우는 것이 아닙니다.
> **완성된 서비스를 먼저 사용해 보고, 공식 개발 문서에서 필요한 예제를 찾아 실행하고, 내 코드로 바꾸는 경험**을 만드는 것입니다.

## 1. 먼저 결과물부터 만나 봅시다

이 과정의 마지막에는 사용자의 질문을 받아 처리하고 결과를 화면에 보여 주는 작은 AI 서비스를 완성합니다.

### 완성 결과물에서 확인할 장면

1. 사용자가 Streamlit 화면에 질문을 입력합니다.
2. 화면은 질문을 JSON 데이터로 만들어 FastAPI 서버에 보냅니다.
3. Pydantic이 입력 데이터가 올바른지 검사합니다.
4. 비동기 서비스 로직이 요청을 처리합니다.
5. 처리 결과가 다시 화면에 표시됩니다.
6. 잘못된 요청을 보내면 원인을 알 수 있는 오류 응답이 나타납니다.

첫 수업에서는 설명보다 먼저 다음 장면을 직접 시연합니다.

- 정상 질문을 보내고 답변 확인하기
- 입력값을 일부러 잘못 보내 검증 오류 확인하기
- FastAPI의 `/docs`에서 API를 직접 실행하기
- 터미널 로그에서 요청이 이동하는 과정 추적하기

## 2. 결과물의 전체 아키텍처

```text
┌──────────┐     입력·결과      ┌─────────────────┐
│  사용자   │ ◀──────────────▶ │ Streamlit Web UI │
└──────────┘                    └────────┬────────┘
                                        │ HTTP / JSON
                                        ▼
                              ┌────────────────────┐
                              │ FastAPI REST API   │
                              │  ┌──────────────┐  │
                              │  │ Pydantic 검증 │  │
                              │  └──────┬───────┘  │
                              └─────────┼──────────┘
                                        │ 검증된 데이터
                                        ▼
                              ┌────────────────────┐
                              │ async 서비스 로직  │
                              │ AI·외부 API·DB 연결 │
                              └────────────────────┘
```

각 기술은 혼자 동작하는 섬이 아니라, 데이터를 다음 단계로 안전하게 전달하는 하나의 팀입니다.

| 기술 | 결과물에서 맡는 역할 | 기억할 한 문장 |
|---|---|---|
| Python | 전체 서비스 로직 작성 | 모든 부품을 연결하는 기본 언어 |
| 클래스·예외·로깅 | 코드 재사용과 오류 추적 | 문제가 나도 원인을 찾을 수 있게 만들기 |
| `asyncio` | 기다림이 많은 작업을 효율적으로 처리 | 기다리는 동안 다른 일을 하기 |
| Pydantic | 입력·출력 데이터의 타입과 규칙 검증 | 서버 입구의 안전요원 |
| FastAPI | REST API와 자동 API 문서 제공 | 화면과 서비스 로직을 연결하는 창구 |
| Streamlit | 사용자가 만지는 웹 화면 제작 | Python만으로 빠르게 만드는 프런트엔드 |

## 3. 공식 개발 문서에서 출발하기

개발자는 모든 코드를 기억하는 사람이 아니라, **신뢰할 수 있는 문서에서 필요한 내용을 빠르게 찾는 사람**입니다. 아래 링크는 검색 결과나 블로그가 아닌 각 기술의 공식 문서입니다.

| 기술 | 공식 문서 | 첫 번째 따라 하기 미션 |
|---|---|---|
| Python | [Python 공식 튜토리얼](https://docs.python.org/3/tutorial/) | 변수 하나를 바꾸고 다시 실행하기 |
| Python 타입 힌트 | [`typing` 공식 문서](https://docs.python.org/3/library/typing.html) | 함수의 매개변수와 반환 타입 표시하기 |
| 비동기 처리 | [`asyncio` 공식 문서](https://docs.python.org/3/library/asyncio.html) | `async`와 `await`가 있는 예제 찾기 |
| Pydantic | [Pydantic Models](https://docs.pydantic.dev/latest/concepts/models/) | 입력 모델을 만들고 잘못된 값 넣어 보기 |
| FastAPI | [FastAPI 첫 단계](https://fastapi.tiangolo.com/tutorial/first-steps/) | 첫 API를 실행하고 `/docs` 열기 |
| Streamlit | [Streamlit 시작하기](https://docs.streamlit.io/get-started) | 제목과 버튼이 있는 앱 실행하기 |
|  | [30days Streamlit](https://30days.streamlit.app/?challenge=Day1) | 제목과 버튼이 있는 앱 실행하기 |

### 문서를 따라 하는 4단계 규칙

```text
찾기 → 복사하기 → 실행하기 → 한 가지 바꾸기
```

예제를 그대로 실행하는 것은 출발점입니다. 문자열, 숫자, 함수 이름 또는 화면 요소 중 **반드시 한 가지를 바꾸고 결과를 설명**하면 내 코드가 됩니다.

## 4. 공식 문서 보물찾기

2~3명씩 팀을 만들고 기술 하나를 선택합니다.

1. 위 표에서 공식 문서를 엽니다.
2. 가장 짧은 실행 예제를 찾습니다.
3. 예제를 실행해 성공 화면을 만듭니다.
4. 코드 한 줄을 바꾸고 결과를 예측합니다.
5. 다른 팀에게 다음 세 가지만 소개합니다.

```text
이 기술은 어디에 사용하는가?
가장 먼저 실행한 코드는 무엇인가?
한 줄을 바꾸자 결과가 어떻게 달라졌는가?
```

오류가 발생한 팀은 실패한 팀이 아닙니다. **오류 메시지에서 단서를 가장 먼저 찾아낸 팀**입니다.

## 5. 첫날의 미니 성공 경험

오늘은 다음과 같은 작은 API를 직접 실행하는 것을 첫 번째 목표로 삼습니다.

```python
from fastapi import FastAPI
from pydantic import BaseModel

app = FastAPI()


class Question(BaseModel):
    message: str


@app.post("/ask")
async def ask(question: Question):
    return {"answer": f"첫 질문을 받았습니다: {question.message}"}
```

이 짧은 코드 안에도 앞으로 배울 핵심이 들어 있습니다.

- `Question`: Pydantic 데이터 검증
- `@app.post("/ask")`: FastAPI의 API 주소
- `async def`: 비동기 함수
- `dict` 반환값: 화면으로 전달할 JSON 응답

완벽하게 이해한 뒤 실행하는 것이 아니라, **먼저 실행하고 결과를 관찰한 뒤 구조를 하나씩 분해**합니다.

## 6. 첫 만남 수업 진행 예시

| 시간 | 활동 | 교육생이 얻는 결과 |
|---:|---|---|
| 0~10분 | 완성 서비스 시연 | 우리가 만들 결과물의 모습 이해 |
| 10~20분 | 아키텍처에서 요청의 이동 추적 | 기술들이 연결되는 이유 이해 |
| 20~45분 | 공식 문서 보물찾기 | 문서에서 예제를 찾는 경험 |
| 45~65분 | 가장 작은 예제 실행·변경 | 첫 실행 성공 경험 |
| 65~80분 | 팀별 3분 공유 | 기술의 역할을 자기 말로 설명 |
| 80~90분 | 오류 자랑 대회와 과정 예고 | 오류를 학습 재료로 보는 태도 형성 |

수업 시간에 맞게 활동 시간을 늘리거나 줄여 사용할 수 있습니다.

## 7. 앞으로의 학습 흐름

```text
Python 문법
  → 재사용 가능한 클래스와 안전한 오류 처리
  → asyncio 비동기 실행
  → Pydantic 데이터 검증
  → FastAPI REST API
  → Streamlit 사용자 화면
  → 하나의 AI 서비스로 통합
```

각 장에서는 작은 코드를 실행하고, 마지막에는 처음 시연했던 서비스의 구조로 다시 연결합니다.
