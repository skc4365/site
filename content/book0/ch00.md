# AI 서비스 프로그래밍

## 학습 흐름

```text
Python 문법
  → 재사용 가능한 클래스와 안전한 오류 처리
  → asyncio 비동기 실행
  → Pydantic 데이터 검증
  → FastAPI REST API
  → Streamlit 사용자 화면
```

## 기술 스택

| 기술 | 과정에서 하는 일 |
|---|---|
| Python | 서비스 로직 작성 |
| asyncio | 여러 작업을 기다리는 동안 효율적으로 실행 |
| Pydantic | 입력·출력 데이터 타입과 규칙 검증 |
| FastAPI | RESTful API 제공 |
| Streamlit | API를 사용하는 간단한 웹 UI 제작 |

## 최종 결과

```text
사용자 → Streamlit UI → FastAPI → Pydantic 검증
                              ↓
                       async 서비스 로직
```

각 장에서 작은 코드를 실행하고, Chapter 6에서 하나의 AI 서비스 형태로 연결합니다.
