# 사전 정의 체인(Chain) — 정해진 순서로 AI 작업을 실행하는 구조

## 개념

**Chain**은 Prompt, Model, Parser 같은 작업을 미리 정한 순서로 연결한 처리 흐름입니다.

```text
입력 → Prompt → Model → 출력 형식 변환 → 결과
```

입력과 실행 순서가 같으면 결과 구조도 예측하기 쉬워집니다.

## 언제 사용하는가

- 요약·분류·번역처럼 처리 순서가 항상 같을 때
- 출력 형식을 Pydantic 모델이나 JSON으로 고정할 때
- 각 단계를 따로 시험하고 재사용할 때

## 아키텍처

```text
dict 입력
   ↓
ChatPromptTemplate ──> PromptValue
   ↓
Chat Model ──────────> AIMessage 또는 구조화 객체
   ↓
Parser ──────────────> str·dict·Pydantic Model
```

## 핵심 원리

LangChain의 구성 요소는 공통 `Runnable` 규약을 사용합니다.

```text
output(A) = input(B)
A | B | C = RunnableSequence(A, B, C)
```

앞 단계의 출력 타입이 다음 단계 입력 타입과 맞아야 합니다. `invoke()`는 입력 한 건, `batch()`는 여러 건, `stream()`은 생성 중인 결과를 처리합니다.

## 바로 실행하는 코드

```bash
pip install -U langchain langchain-openai pydantic
```

`OPENAI_API_KEY` 환경 변수를 설정한 뒤 실행합니다.

```python
from typing import Literal

from langchain_core.prompts import ChatPromptTemplate
from langchain_openai import ChatOpenAI
from pydantic import BaseModel, Field


class Quiz(BaseModel):
    question: str = Field(description="퀴즈 문제")
    level: Literal["쉬움", "보통", "어려움"]
    options: list[str] = Field(min_length=4, max_length=4)


prompt = ChatPromptTemplate.from_messages(
    [
        ("system", "주어진 주제로 한국어 4지선다 문제를 만드세요."),
        ("human", "주제: {topic}"),
    ]
)
model = ChatOpenAI(model="gpt-4.1-mini", temperature=0)
structured_model = model.with_structured_output(Quiz)

chain = prompt | structured_model
quiz = chain.invoke({"topic": "Python 리스트"})

print(quiz.question, f"({quiz.level})")
for number, option in enumerate(quiz.options, start=1):
    print(number, option)
```

## 코드에서 볼 부분

```python
chain = prompt | structured_model
quiz = chain.invoke({"topic": "Python 리스트"})
```

`dict`가 Prompt에 들어가고, PromptValue가 모델에 전달되며, 마지막에는 검증된 `Quiz` 객체가 반환됩니다.

## 요점 정리

1. Chain은 정해진 작업을 정해진 순서로 실행합니다.
2. `|`는 Runnable의 출력을 다음 Runnable 입력으로 연결합니다.
3. 단계 사이의 데이터 타입이 맞아야 합니다.
4. 구조화 출력은 후속 코드가 사용할 결과 계약을 만듭니다.
5. 분기·반복·상태가 복잡하면 단순 Chain보다 Graph를 검토합니다.
