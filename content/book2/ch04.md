# LCEL 고급 문법으로 Runnable 활용하기

## 먼저 보는 구조

```text
입력 → 병렬 실행·라우팅 → 결과 결합
```

## 핵심 개념

- RunnableLambda
- RunnableParallel
- 조건 라우팅과 fallback

## 기본 코드

```python
parallel = RunnableParallel(summary=summary_chain, keywords=keyword_chain)
result = parallel.invoke({'text': text})
```

## 코드 읽기

1. 입력과 출력 데이터 구조를 확인합니다.
2. 외부 서비스와 비용이 발생하는 지점을 찾습니다.
3. 한 단계씩 따로 실행해 중간 결과를 확인합니다.
4. 실패와 시간 초과를 처리합니다.
