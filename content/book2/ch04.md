# LCEL 고급 — 순차·병렬·조건 실행을 Runnable로 조합하는 방법

## 개념

**LCEL(LangChain Expression Language)**은 Runnable을 `|`와 dict 형태로 연결해 실행 흐름을 선언하는 방식입니다.

```text
순차 실행: A | B | C
병렬 실행: {"a": A, "b": B}
```

## 언제 사용하는가

- 같은 입력으로 요약과 키워드 추출을 동시에 실행할 때
- Python 함수를 Chain 중간 단계로 넣을 때
- 실패 시 대체 모델이나 체인으로 전환할 때

## 아키텍처

```text
                    ┌─> summary ──┐
입력 → 전처리 ──────┤              ├─> dict 결과
                    └─> keywords ─┘
```

병렬 실행은 서로 의존하지 않는 작업에 사용합니다. 한 작업의 결과가 다음 작업에 필요하다면 순차 실행이어야 합니다.

## 핵심 원리

| 구성 요소 | 역할 |
|---|---|
| `RunnableLambda` | 일반 Python 함수를 Runnable로 변환 |
| `RunnableSequence` | 앞 단계 출력을 다음 단계로 전달 |
| `RunnableParallel` | 같은 입력을 여러 Runnable에 전달 |
| `with_fallbacks()` | 기본 실행 실패 시 대체 실행 사용 |

병렬 처리 시간은 이상적으로 다음 값에 가까워집니다.

```text
순차 시간 ≈ T1 + T2
병렬 시간 ≈ max(T1, T2)
```

## 바로 실행하는 코드

```bash
pip install -U langchain-core
```

```python
from langchain_core.runnables import RunnableLambda, RunnableParallel


def summarize(text: str) -> str:
    return text[:25] + "..." if len(text) > 25 else text


def keywords(text: str) -> list[str]:
    words = text.replace(".", "").split()
    return sorted(set(words), key=len, reverse=True)[:3]


parallel = RunnableParallel(
    summary=RunnableLambda(summarize),
    keywords=RunnableLambda(keywords),
)

result = parallel.invoke(
    "LangChain Runnable은 AI 애플리케이션의 실행 단계를 조합한다."
)
print(result)
```

## 코드에서 볼 부분

```python
parallel = RunnableParallel(summary=..., keywords=...)
```

두 Runnable은 동일한 문자열을 입력받고, 결과는 `{"summary": ..., "keywords": ...}` 형태로 합쳐집니다.

## 요점 정리

1. LCEL은 실행 흐름을 선언적으로 표현합니다.
2. `|`는 순차 실행, `RunnableParallel`은 독립 작업의 병렬 실행입니다.
3. `RunnableLambda`는 Python 함수를 Chain에 연결합니다.
4. 병렬화해도 외부 API의 Rate Limit은 별도로 고려해야 합니다.
5. fallback은 장애를 숨기는 기능이 아니라 제한된 복구 전략입니다.
