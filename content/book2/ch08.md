# AI 에이전트 주요 기능

## 먼저 보는 구조

```text
사용자 → Agent → Tool → 관찰 → 최종 답변
```

## 핵심 개념

- create_agent
- 도구 반복
- 메모리와 사용자 승인

## 기본 코드

```python
agent = create_agent(model=model, tools=tools, system_prompt='필요한 도구만 사용하세요.')
result = agent.invoke({'messages': [{'role': 'user', 'content': question}]})
```

## 코드 읽기

1. 입력과 출력 데이터 구조를 확인합니다.
2. 외부 서비스와 비용이 발생하는 지점을 찾습니다.
3. 한 단계씩 따로 실행해 중간 결과를 확인합니다.
4. 실패와 시간 초과를 처리합니다.
