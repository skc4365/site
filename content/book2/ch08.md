# AI 에이전트(Agent) — 모델이 도구를 선택하고 목표를 완료하는 실행 루프

## 개념

**AI Agent**는 사용자의 목표를 받아 모델이 필요한 도구를 선택하고, 실행 결과를 확인하며, 최종 답변까지 반복하는 시스템입니다.

```text
Agent = Model + Tools + 실행 루프 + State
```

도구 없이 답변만 생성하면 일반적인 LLM 호출입니다.

## 언제 사용하는가

- 질문마다 사용할 도구와 실행 순서가 달라질 때
- 검색·계산·API 호출을 여러 번 조합해야 할 때
- 고정 Chain으로 모든 분기를 미리 작성하기 어려울 때

## 아키텍처

```text
사용자 → Agent State → Model
                       ├─ 최종 답변 → 종료
                       └─ Tool Call
                             ↓
                         Tool 실행
                             ↓ ToolMessage
                         State 갱신 ──> Model 반복
```

## 핵심 원리

Agent의 한 번의 반복은 다음 상태 전이로 볼 수 있습니다.

```text
state_(t+1) = state_t + AIMessage + ToolMessage
```

모델이 최종 답변을 내거나 최대 반복 횟수·종료 조건에 도달하면 멈춥니다.

## 바로 실행하는 코드

```bash
pip install -U langchain langchain-openai
```

`OPENAI_API_KEY` 환경 변수를 설정한 뒤 실행합니다.

```python
from langchain.agents import create_agent
from langchain.tools import tool


@tool
def multiply(a: int, b: int) -> int:
    """두 정수를 곱합니다."""
    return a * b


agent = create_agent(
    model="openai:gpt-4.1-mini",
    tools=[multiply],
    system_prompt="계산이 필요하면 반드시 도구를 사용하세요.",
)

result = agent.invoke(
    {"messages": [{"role": "user", "content": "123과 45를 곱해줘."}]}
)
print(result["messages"][-1].content)
```

## 코드에서 볼 부분

```python
result = agent.invoke({"messages": [...]})
```

반환값은 문자열이 아니라 State입니다. `messages`에는 사용자 요청, 모델의 Tool Call, Tool 결과, 최종 답변이 순서대로 들어갑니다.

## Agent를 쓰지 않아도 되는 경우

| 상황 | 더 단순한 선택 |
|---|---|
| 실행 순서가 항상 같음 | Chain·Workflow |
| 도구가 하나이고 호출 조건이 명확함 | 일반 Python 조건문 |
| 결과 형식만 고정하면 됨 | Structured Output |

## 요점 정리

1. Agent는 모델·도구·State를 반복 실행하는 시스템입니다.
2. 모델이 도구를 선택하지만 실제 함수 실행은 Agent Runtime이 담당합니다.
3. Agent 결과는 전체 메시지를 포함한 State로 확인합니다.
4. 반복 횟수, 시간 제한, 도구 권한과 종료 조건이 필요합니다.
5. 정해진 순서의 작업에는 Agent보다 단순한 Chain이 적합합니다.
