# AI 에이전트 도구(Tool) — 모델의 판단을 실제 Python 기능과 연결하는 방법

## 개념

**Tool**은 Agent가 사용할 수 있도록 이름, 설명, 입력 스키마를 붙인 실행 함수입니다.

```text
LLM: 어떤 도구를 어떤 인자로 호출할지 요청한다.
코드: 입력을 검사하고 실제 도구를 실행한다.
```

모델이 Tool Call을 생성하는 것과 Python 함수가 실행되는 것은 별개의 단계입니다.

## 언제 사용하는가

- 계산, 검색, DB 조회처럼 모델만으로 정확히 처리하기 어려울 때
- 이메일 발송이나 파일 저장처럼 외부 상태를 변경할 때
- 현재 시간·재고·사내 데이터처럼 실시간 정보가 필요할 때

## 아키텍처

```text
사용자 질문 → LLM
                ↓ Tool Call(name, arguments)
           입력 검증·권한 검사
                ↓
           Python Tool 실행
                ↓ ToolMessage
              LLM → 최종 답변
```

## 핵심 원리

도구는 다음 계약으로 표현됩니다.

```text
Tool = name + description + input_schema + function
```

- 이름과 설명은 모델의 도구 선택에 사용됩니다.
- 타입 힌트는 입력 JSON Schema 생성에 사용됩니다.
- 실제 실행 권한과 오류 처리는 애플리케이션이 담당합니다.

## 바로 실행하는 코드

```bash
pip install -U langchain-core
```

```python
from langchain_core.tools import tool


@tool
def calculate_total(price: int, quantity: int) -> int:
    """상품의 단가와 수량으로 총금액을 계산합니다."""
    if price < 0 or quantity < 0:
        raise ValueError("단가와 수량은 0 이상이어야 합니다.")
    return price * quantity


print("이름:", calculate_total.name)
print("설명:", calculate_total.description)
print("입력 스키마:", calculate_total.args_schema.model_json_schema())
print("실행 결과:", calculate_total.invoke({"price": 1200, "quantity": 3}))
```

## 모델에 연결하는 위치

```python
model_with_tools = model.bind_tools([calculate_total])
ai_message = model_with_tools.invoke("1200원짜리 상품 3개의 총액은?")

for tool_call in ai_message.tool_calls:
    print(tool_call["name"], tool_call["args"])
```

이 코드는 Tool Call을 확인하는 단계입니다. 자동 실행 Agent가 아니라면 `args`를 검증한 뒤 해당 도구를 직접 실행해야 합니다.

## 읽기 도구와 쓰기 도구

| 종류 | 예 | 기본 정책 |
|---|---|---|
| 읽기 | 검색, 조회, 계산 | 범위·시간 제한 적용 |
| 쓰기 | 발송, 삭제, 결제 | 사용자 승인과 감사 로그 적용 |

## 요점 정리

1. Tool은 모델이 사용할 수 있도록 스키마를 붙인 함수입니다.
2. 모델은 호출을 요청하고, 실제 실행은 애플리케이션이 담당합니다.
3. 구체적인 이름·설명·타입이 올바른 도구 선택을 돕습니다.
4. 도구 함수는 Agent에 연결하기 전에 단독 시험합니다.
5. 외부 상태를 바꾸는 도구에는 승인과 권한 검사가 필요합니다.
