## 검토 결과

기존 문서는 기본 AgentExecutor와 대화 기록을 포함하지만, 현재 `create_agent` 흐름과 사람 승인, 실행 한도 설정이 빠져 있습니다. 쓰기·전송·SQL 실행 도구를 사용하는 에이전트 교육에는 반드시 필요한 안전 장치입니다.

## 현재 방식의 기본 에이전트

```python
from langchain.agents import create_agent
from langchain.tools import tool


@tool
def get_machine_status(machine_id: str) -> str:
    """설비 ID로 현재 상태를 조회합니다."""
    return f"{machine_id}: normal"


agent = create_agent(
    model="openai:gpt-4.1-mini",
    tools=[get_machine_status],
    system_prompt="설비 상태를 확인하고 근거 없이 추측하지 마세요.",
)

result = agent.invoke(
    {"messages": [{"role": "user", "content": "MOTOR-01 상태를 확인해 줘"}]}
)
print(result["messages"][-1].content)
```

## 위험한 도구에 사람 승인 추가

```python
from langchain.agents.middleware import HumanInTheLoopMiddleware
from langgraph.checkpoint.memory import InMemorySaver

agent = create_agent(
    model="openai:gpt-4.1-mini",
    tools=[get_machine_status, create_work_order],
    checkpointer=InMemorySaver(),
    middleware=[
        HumanInTheLoopMiddleware(
            interrupt_on={
                "get_machine_status": False,
                "create_work_order": {"allowed_decisions": ["approve", "reject"]},
            }
        )
    ],
)
```

## 필수 안전 기준

- 조회 도구와 변경 도구를 분리합니다.
- 파일 쓰기, 이메일 전송, SQL 변경, 작업지시 생성은 승인 대상으로 지정합니다.
- 도구 입력값을 스키마로 검증하고 대상 범위를 제한합니다.
- 모델 호출 수와 도구 호출 수에 상한을 둡니다.
- 도구 호출 요청·결과·승인자를 감사 로그로 남깁니다.
