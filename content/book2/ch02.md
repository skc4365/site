# RAG 파이프라인 — 외부 문서를 검색해 근거 있는 답변을 만드는 구조

## 개념

**RAG(Retrieval-Augmented Generation)**는 질문과 관련된 외부 문서를 먼저 검색하고, 그 문서를 LLM의 Context로 제공해 답변을 생성하는 방식입니다.

```text
RAG = Retrieval(검색) + Augmented(문맥 보강) + Generation(생성)
```

## 언제 사용하는가

- 사내 문서나 최신 자료처럼 모델 학습 밖의 정보가 필요할 때
- 답변과 함께 출처를 제공해야 할 때
- 모델을 재학습하지 않고 지식 문서를 갱신해야 할 때

## 아키텍처

```text
[문서 준비: 문서가 바뀔 때]
원문 → Load → Split → Embed → Vector Store

[질문 처리: 요청마다]
질문 → Retrieve → 관련 Chunk → Prompt Context → LLM → 답변·출처
```

문서 준비와 질문 처리를 분리하면 검색 문제와 생성 문제를 따로 점검할 수 있습니다.

## 핵심 원리

| 단계 | 입력 | 출력 | 역할 |
|---|---|---|---|
| Load | PDF·Web·DB | `Document` | 원천 데이터를 표준화 |
| Split | 긴 문서 | Chunk 목록 | 검색 가능한 크기로 분할 |
| Embed | Chunk | Vector | 의미를 숫자로 표현 |
| Store | Vector·metadata | Index | 벡터 저장과 검색 |
| Retrieve | 질문 | 관련 Document | 근거 후보 선택 |
| Generate | 질문·Context | 답변 | 근거 기반 문장 생성 |

RAG의 답변 품질은 대략 다음 두 요소에 달려 있습니다.

```text
최종 품질 = 검색 품질 × 생성 품질
```

정답 문서를 검색하지 못하면 좋은 LLM도 근거 있는 답을 만들기 어렵습니다.

## 바로 실행하는 코드

```bash
pip install -U langchain langchain-openai langchain-text-splitters
```

`OPENAI_API_KEY` 환경 변수를 설정한 뒤 실행합니다.

```python
from langchain_core.documents import Document
from langchain_core.prompts import ChatPromptTemplate
from langchain_core.vectorstores import InMemoryVectorStore
from langchain_openai import ChatOpenAI, OpenAIEmbeddings
from langchain_text_splitters import RecursiveCharacterTextSplitter

documents = [
    Document(
        page_content="Python의 append()는 리스트 끝에 항목 하나를 추가한다.",
        metadata={"source": "python-guide", "page": 1},
    ),
    Document(
        page_content="Python의 pop()은 리스트에서 항목을 제거하고 반환한다.",
        metadata={"source": "python-guide", "page": 2},
    ),
]

splitter = RecursiveCharacterTextSplitter(chunk_size=100, chunk_overlap=10)
chunks = splitter.split_documents(documents)

store = InMemoryVectorStore.from_documents(chunks, OpenAIEmbeddings())
retriever = store.as_retriever(search_kwargs={"k": 1})

question = "리스트 끝에 값을 추가하려면?"
found = retriever.invoke(question)
context = "\n\n".join(doc.page_content for doc in found)

prompt = ChatPromptTemplate.from_template(
    "다음 문서만 사용해 답하세요.\n문서: {context}\n질문: {question}"
)
model = ChatOpenAI(model="gpt-4.1-mini", temperature=0)
answer = model.invoke(prompt.invoke({"context": context, "question": question}))

print(answer.content)
print("출처:", found[0].metadata)
```

## 코드에서 볼 부분

```python
found = retriever.invoke(question)
context = "\n\n".join(doc.page_content for doc in found)
```

Retriever는 답을 만들지 않고 `Document`를 반환합니다. 검색 문서의 본문은 Prompt에 넣고 metadata는 출처 표시에 사용합니다.

## 요점 정리

1. RAG는 외부 문서를 검색해 LLM의 Context를 보강합니다.
2. 문서 준비 단계와 질문 처리 단계는 실행 시점이 다릅니다.
3. Retriever는 문서를 찾고 LLM은 그 문서로 답변을 만듭니다.
4. 검색 실패와 생성 실패를 분리해 평가해야 합니다.
5. 출처는 모델이 만들게 하지 말고 `Document.metadata`에서 가져옵니다.
