## 검토 결과

기존 문서는 구조화 출력 체인만 포함합니다. 원본의 요약·SQL·구조화 데이터 대화는 서로 다른 데이터 처리 패턴이므로 학습 예제로 유지할 가치가 있습니다. 다만 구형 Chain 클래스보다 모델·Runnable·Agent를 조합하는 현재 방식을 우선합니다.

| 원본 | 필요성 | 현재 적용 방향 |
| --- | --- | --- |
| `01-Summary` | 필수 | 긴 문서 분할 후 단계적 요약 |
| `02-SQL` | 필수 | 읽기 전용 SQL 도구와 실행 승인 |
| `03-Structured-Output-Chain` | 필수 | `with_structured_output()` |
| `04-Structured-Data-Chat` | 선택 | 데이터프레임·표 전용 도구 |

## 구조화 출력

```python
from typing import Literal
from pydantic import BaseModel, Field
from langchain_openai import ChatOpenAI


class InspectionQuiz(BaseModel):
    question: str = Field(description="점검 문제")
    answer: str = Field(description="정답")
    difficulty: Literal["easy", "medium", "hard"]


model = ChatOpenAI(model="gpt-4.1-mini", temperature=0)
quiz_model = model.with_structured_output(InspectionQuiz)
quiz = quiz_model.invoke("모터 과열 대응에 관한 중간 난이도 문제를 만드세요.")
print(quiz.model_dump())
```

## 긴 문서 요약 흐름

```text
문서 로드 → 적절한 크기로 분할 → 청크별 핵심 요약
         → 중복 제거 및 통합 → 근거 문서 ID와 함께 저장
```

## SQL 학습 시 안전 원칙

- 교육용 읽기 전용 데이터베이스 계정을 사용합니다.
- 허용할 테이블과 SQL 작업을 제한합니다.
- 모델이 만든 SQL을 실행 전에 출력하고 검토합니다.
- `DELETE`, `UPDATE`, `DROP` 같은 변경 작업에는 사람의 승인을 요구합니다.
- 조회 행 수와 실행 시간을 제한합니다.
