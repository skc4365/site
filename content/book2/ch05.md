# RAGAS — RAG의 검색과 생성 품질을 수치로 평가하는 프레임워크

## 개념

**RAGAS(Retrieval-Augmented Generation Assessment)**는 RAG 파이프라인을 검색과 생성 단계로 나누어 평가합니다.

## 언제 사용하는가

- 답변 오류가 검색기와 생성기 중 어디서 발생했는지 찾을 때
- Chunk, Embedding, Prompt, Model 변경 전후를 비교할 때
- 배포 전에 고정 평가셋으로 품질 저하를 검사할 때

## 아키텍처

```text
질문 → Retriever → Context → LLM → 답변
          ↑                       ↑
  Precision·Recall      Faithfulness·Relevancy
```

## 평가 데이터

| 의미 | Ragas 필드 | 생성 위치 |
|---|---|---|
| 질문 | `user_input` | 사용자·평가셋 |
| 검색 문서 | `retrieved_contexts` | Retriever |
| 생성 답변 | `response` | LLM |
| 기준 답변 | `reference` | 사람이 검수한 평가셋 |

## 핵심 4지표

| 지표 | 확인하는 내용 | 낮을 때 먼저 볼 곳 |
|---|---|---|
| Context Precision | 관련 문서가 상위에 있는가 | Retriever·Reranker·필터 |
| Context Recall | 필요한 근거를 빠짐없이 찾았는가 | Loader·Chunk·`k` |
| Faithfulness | 답변 주장이 Context에 근거하는가 | Prompt·LLM |
| Response Relevancy | 답변이 질문 의도를 해결하는가 | Prompt·질문 전달 |

대표 계산 방향은 다음과 같습니다.

```text
Context Recall = 검색 근거가 지원한 기준 답변 주장 / 기준 답변의 전체 주장
Faithfulness   = Context가 지원한 답변 주장 / 답변의 전체 주장
```

## 점수 조합으로 원인 찾기

| Precision | Recall | Faithfulness | 해석 |
|:---:|:---:|:---:|---|
| 낮음 | 높음 | 높음 | 필요한 문서는 있지만 무관한 결과가 앞에 많음 |
| 높음 | 낮음 | 높음 | 정확한 일부 문서만 찾고 필요한 근거를 놓침 |
| 높음 | 높음 | 낮음 | 검색은 성공했지만 LLM이 근거 밖 내용을 생성 |

## 바로 실행하는 코드

```bash
pip install -U ragas openai
```

`OPENAI_API_KEY` 환경 변수를 설정한 뒤 실행합니다.

```python
import asyncio
from openai import AsyncOpenAI
from ragas.llms import llm_factory
from ragas.metrics.collections import ContextRecall, Faithfulness


async def main() -> None:
    evaluator_llm = llm_factory("gpt-4o-mini", client=AsyncOpenAI())

    data = {
        "user_input": "에펠탑은 어디에 있나요?",
        "retrieved_contexts": ["에펠탑은 프랑스 파리에 있다."],
        "response": "에펠탑은 파리에 있습니다.",
        "reference": "에펠탑은 프랑스 파리에 있습니다.",
    }

    recall = await ContextRecall(llm=evaluator_llm).ascore(
        user_input=data["user_input"],
        retrieved_contexts=data["retrieved_contexts"],
        reference=data["reference"],
    )
    faithfulness = await Faithfulness(llm=evaluator_llm).ascore(
        user_input=data["user_input"],
        retrieved_contexts=data["retrieved_contexts"],
        response=data["response"],
    )

    print("Context Recall:", recall.value)
    print("Faithfulness:", faithfulness.value)


asyncio.run(main())
```

## 요점 정리

1. RAGAS는 검색과 생성 실패를 나누어 진단합니다.
2. Precision은 관련 문서의 순위, Recall은 필요한 정보의 누락을 봅니다.
3. Faithfulness는 근거 충실성, Relevancy는 질문과 답변의 일치를 봅니다.
4. 평균 점수만 보지 말고 낮은 개별 사례의 Context와 답변을 확인합니다.
5. Ragas 버전과 평가용 모델을 고정해야 비교 결과가 일관됩니다.
