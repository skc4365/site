# 리랭커(Reranker) — 검색 결과를 관련도 순으로 다시 정렬하는 기술

## 개념

**리랭커**는 Retriever가 찾은 후보 문서를 질문과 다시 비교하여, **더 관련 있는 문서가 위에 오도록 순서를 바꾸는 모델**입니다.

```text
Retriever: 빠르게 후보를 찾는다.
Reranker:  후보를 정밀하게 다시 정렬한다.
```

리랭커는 전체 문서를 검색하지 않습니다. 이미 검색된 후보 안에서 LLM에 전달할 문서를 고릅니다.

## 언제 사용하는가

- 검색 상위 결과에 관련 없는 문서가 섞일 때
- 질문의 세부 조건까지 구분해야 할 때
- 많은 후보 중 소수의 근거만 LLM에 전달할 때

예를 들어 “Python 리스트 끝에 값을 추가하는 방법”이라는 질문에는 `append()`를 설명하는 문서가 가장 먼저 와야 합니다.

## 아키텍처

```text
질문
  ↓
Retriever ── 빠른 1차 검색 ──> 후보 N개
                                ↓
Reranker ── 정밀한 2차 평가 ──> 상위 K개
                                ↓
                         LLM Context → 답변
```

보통 `N > K`로 설정합니다.

- `N`: 리랭커가 평가할 후보 수. 예: 20개
- `K`: LLM에 전달할 최종 문서 수. 예: 3개

## 핵심 원리

### 1차 검색: Bi-encoder

질문과 문서를 각각 벡터로 만든 뒤 유사도를 계산합니다.

```text
similarity(q, d) = (q · d) / (||q|| × ||d||)
```

문서 벡터를 미리 저장할 수 있어 빠르지만, 질문과 문서의 세부 관계를 놓칠 수 있습니다.

### 2차 정렬: Cross-encoder

질문과 후보 문서를 한 쌍으로 함께 읽고 관련도 점수를 계산합니다.

```text
score_i = f(question, document_i)
result = TopK(score가 높은 문서)
```

정밀하지만 후보마다 모델을 실행하므로 느립니다. 따라서 전체 문서가 아닌 1차 검색 후보에만 적용합니다.

## Retriever와 Reranker 비교

| 구분 | Retriever | Reranker |
|---|---|---|
| 역할 | 후보 검색 | 후보 재정렬 |
| 범위 | 전체 문서 | 후보 N개 |
| 방식 | BM25, Vector Search | Cross-encoder, Rerank API |
| 장점 | 빠름 | 정밀함 |
| 출력 | 후보 목록 | 관련도순 상위 K개 |

## 바로 실행하는 코드

```bash
pip install -U sentence-transformers
```

```python
from sentence_transformers import CrossEncoder

question = "How do I add an item to the end of a Python list?"
candidates = [
    "Use list.append(item) to add one item to the end of a Python list.",
    "A Python tuple is immutable after it is created.",
    "Use list.insert(index, item) to place an item at a specific position.",
    "The pop() method removes and returns an item from a list.",
    "Use list.extend(iterable) to append all items from another iterable.",
]

# 질문과 각 후보를 함께 평가하는 소형 Cross-encoder
reranker = CrossEncoder("cross-encoder/ms-marco-TinyBERT-L2-v2")

ranked = reranker.rank(
    question,
    candidates,
    top_k=3,
    return_documents=True,
)

for rank, item in enumerate(ranked, start=1):
    print(f"{rank}위 | score={item['score']:.4f}")
    print(item["text"])
```

최초 실행 시 모델을 내려받습니다. 결과에서는 `list.append(item)` 문서가 상위에 배치되어야 합니다.

## 코드에서 볼 부분

```python
ranked = reranker.rank(question, candidates, top_k=3)
```

이 코드는 다음 작업을 한 번에 수행합니다.

1. 질문과 후보 문서를 각각 한 쌍으로 만듭니다.
2. 각 쌍의 관련도 점수를 계산합니다.
3. 점수가 높은 순서로 정렬합니다.
4. 상위 3개만 반환합니다.

점수는 모델 안에서 문서 순위를 비교하는 값입니다. 모든 모델에서 0~1 확률로 해석할 수 있는 것은 아닙니다.

## LangChain에서 사용하는 위치

```python
candidates = retriever.invoke(question)                   # 후보 N개 검색
ranked = reranker.compress_documents(candidates, question)  # 재정렬
final_docs = list(ranked)[:3]                            # 상위 K개 선택
```

## 요점 정리

1. 리랭커는 **검색기가 아니라 2차 정렬기**입니다.
2. Retriever는 빠르게 후보를 찾고, Reranker는 후보를 정밀하게 평가합니다.
3. Cross-encoder는 질문과 문서를 함께 읽기 때문에 정확하지만 느립니다.
4. 보통 후보 N개를 재정렬해 상위 K개만 LLM에 전달합니다.
5. 정답 문서가 후보 N개에 없다면 리랭커도 찾을 수 없습니다.
