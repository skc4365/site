# 리랭커로 검색된 문서 순위 조정하기

## 먼저 보는 구조

```text
질문 → 1차 검색 N개 → Reranker → 상위 K개
```

## 핵심 개념

- Retriever와 Reranker의 역할 차이
- 후보 수와 최종 문서 수
- 정확도와 지연시간 비교

## 기본 코드

```python
candidates = retriever.invoke(question)
ranked = reranker.compress_documents(candidates, question)
final_docs = list(ranked)[:3]
```
