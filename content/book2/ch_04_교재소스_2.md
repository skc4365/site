## 검토 결과

기존 문서는 `RunnableParallel`만 다룹니다. 고급 LCEL을 이해하려면 입력 전달, 사용자 함수, 분기, 런타임 설정, 실패 대체 경로도 필요합니다.

| 범주 | 원본 예제 | 우선순위 |
| --- | --- | --- |
| 입력 전달 | RunnablePassthrough | 필수 |
| 변환 | RunnableLambda | 필수 |
| 흐름 분기 | Routing | 필수 |
| 병렬 실행 | RunnableParallel | 필수·기존 수록 |
| 런타임 설정 | Configure, Binding | 권장 |
| 상태 | RunnableWithMessageHistory | 메모리 장과 통합 |
| 복구 | Fallbacks | 필수 |
| 커스텀 실행 | ChainDecorator, Generator | 심화 |

## Passthrough와 Lambda

```python
from langchain_core.runnables import RunnableLambda, RunnablePassthrough


def normalize(data: dict) -> dict:
    return {**data, "question": data["question"].strip()}


chain = RunnablePassthrough() | RunnableLambda(normalize)
print(chain.invoke({"question": "  모터 온도 기준은?  "}))
```

## 조건부 라우팅

```python
from langchain_core.runnables import RunnableBranch, RunnableLambda

alarm_chain = RunnableLambda(lambda x: {"route": "alarm", "input": x})
manual_chain = RunnableLambda(lambda x: {"route": "manual", "input": x})

router = RunnableBranch(
    (lambda x: "경고" in x["question"], alarm_chain),
    manual_chain,
)
print(router.invoke({"question": "진동 경고를 확인해 주세요"}))
```

## 병렬 실행

```python
from langchain_core.runnables import RunnableLambda, RunnableParallel

parallel = RunnableParallel(
    length=RunnableLambda(lambda x: len(x["text"])),
    upper=RunnableLambda(lambda x: x["text"].upper()),
)
print(parallel.invoke({"text": "motor warning"}))
```

## 사용 원칙

- 단순 순차 처리는 파이프(`|`)로 표현합니다.
- 독립 작업만 병렬화하며 공유 상태 변경은 피합니다.
- 라우팅 조건은 작은 함수로 분리해 단위 테스트합니다.
- fallback은 장애를 숨기지 않도록 어떤 경로가 사용됐는지 기록합니다.
