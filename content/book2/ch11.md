# LangServe와 API — LangChain 기능을 HTTP 서비스로 제공하는 방법

## 개념

**API 서비스**는 Chain이나 Agent를 서버에서 실행하고, 다른 프로그램이 HTTP 요청과 JSON 응답으로 사용하게 만드는 구조입니다.

**LangServe**는 LangChain Runnable을 FastAPI 경로로 쉽게 노출하도록 돕는 패키지입니다.

## 언제 사용하는가

- 웹·모바일·사내 시스템이 같은 AI 기능을 사용할 때
- UI와 AI 실행 서버를 독립적으로 배포할 때
- 요청 검증, 인증, 로깅, 확장이 필요할 때

## 아키텍처

```text
Client
  ↓ HTTP + JSON
FastAPI / LangServe
  ↓ 입력 검증
Runnable·RAG·Agent
  ↓
JSON 응답
```

네트워크 경계를 만들면 함수 호출에 없던 인증, Timeout, 동시성, 버전 관리가 필요합니다.

## 핵심 원리

```text
API Contract = URL + HTTP Method + Request Schema + Response Schema
```

서버와 Client는 내부 Python 코드가 아니라 이 계약에 의존합니다.

| 항목 | 역할 |
|---|---|
| Pydantic | 요청·응답 자료형 검증 |
| FastAPI | HTTP 경로와 OpenAPI 제공 |
| LangServe | Runnable 표준 경로 자동 생성 |
| Uvicorn | ASGI 애플리케이션 실행 |

## 바로 실행하는 코드

```bash
pip install -U fastapi uvicorn langserve langchain-core
```

다음 코드를 `server.py`로 저장합니다.

```python
from fastapi import FastAPI
from langchain_core.runnables import RunnableLambda
from langserve import add_routes


def answer(question: str) -> str:
    # 실제 프로젝트에서는 RAG Chain이나 Agent를 호출합니다.
    return f"서버가 받은 질문: {question}"


app = FastAPI(title="Book2 AI API", version="1.0")
chain = RunnableLambda(answer)

add_routes(app, chain, path="/answer")
```

서버를 실행합니다.

```bash
uvicorn server:app --reload
```

브라우저에서 `http://127.0.0.1:8000/docs` 또는 LangServe Playground를 확인합니다.

## 생성되는 주요 경로

```text
/answer/invoke        단일 요청
/answer/batch         여러 입력
/answer/stream        스트리밍
/answer/playground/   테스트 화면
```

## 운영에서 추가할 것

- 인증·인가와 사용자별 요청 제한
- 요청 Timeout, 재시도, Rate Limit
- Trace ID와 민감정보를 제외한 로그
- Health Check와 모델 연결 상태 확인
- API 버전과 하위 호환성

## 요점 정리

1. API는 Python 함수를 HTTP와 JSON 경계로 제공합니다.
2. 요청·응답 Schema가 Client와 서버 사이의 계약입니다.
3. LangServe는 Runnable의 invoke·batch·stream 경로를 생성합니다.
4. 배포 후에는 인증, Timeout, 동시성, 로그가 필요합니다.
5. 단순 API는 FastAPI로 직접 만들고, Runnable 표준 노출이 필요하면 LangServe를 검토합니다.
