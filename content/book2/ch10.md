# Streamlit 서비스 배포 실습

## 먼저 보는 구조

```text
브라우저 → Streamlit UI → 서비스 로직 → 응답
```

## 핵심 개념

- UI와 로직 분리
- cache_resource
- 환경변수와 오류 표시

## 기본 코드

```python
@st.cache_resource
def load_service():
    return build_rag_service()
answer = load_service().invoke(question)
```

## 코드 읽기

1. 입력과 출력 데이터 구조를 확인합니다.
2. 외부 서비스와 비용이 발생하는 지점을 찾습니다.
3. 한 단계씩 따로 실행해 중간 결과를 확인합니다.
4. 실패와 시간 초과를 처리합니다.
