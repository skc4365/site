## 검토 결과

기존 문서는 Agentic RAG만 포함합니다. 원본에는 표 데이터 분석, 파일 관리, 보고서 생성, 다중 에이전트 토론 등 서로 다른 활용 패턴이 있어 최소한 용도와 위험도를 비교해야 합니다.

| 원본 활용 | 학습 가치 | 권장 수준 |
| --- | --- | --- |
| Agentic RAG | 검색 여부를 에이전트가 결정 | 필수·기존 수록 |
| CSV·Excel Agent | 구조 데이터 분석 | 필수 |
| File Management | 파일 작업 도구 | 승인 포함 실습 |
| Report + Image | 여러 결과물을 조합 | 선택 프로젝트 |
| Two-Agent Debate | 역할 분리와 결과 통합 | 심화 |
| ReAct Agent | 생각-도구-관찰 반복 | 필수 개념 |

## 활용 방식 선택

```text
작업 순서가 고정됨 → 일반 함수·LCEL·워크플로
도구 선택만 모델이 판단 → 단일 에이전트
역할·권한·상태가 명확히 분리됨 → 다중 에이전트 검토
```

## 구조 데이터 분석 도구 예제

```python
from pathlib import Path
import pandas as pd
from langchain.tools import tool

DATA_DIR = Path("data").resolve()


@tool
def summarize_csv(filename: str) -> str:
    """허용된 data 폴더의 CSV 행 수와 열 이름을 반환합니다."""
    target = (DATA_DIR / filename).resolve()
    if DATA_DIR not in target.parents or target.suffix.lower() != ".csv":
        raise ValueError("허용되지 않은 파일입니다.")
    frame = pd.read_csv(target)
    return f"rows={len(frame)}, columns={list(frame.columns)}"
```

## 적용 원칙

- 에이전트가 없어도 해결 가능한 작업에는 에이전트를 사용하지 않습니다.
- 파일 도구는 허용된 기준 폴더 밖으로 나갈 수 없게 검증합니다.
- 데이터 분석 도구는 원본 데이터를 수정하지 않는 읽기 전용으로 시작합니다.
- 다중 에이전트는 역할 수보다 결과 검증과 종료 조건을 먼저 설계합니다.
- 결과에는 사용한 도구와 근거 문서를 표시합니다.
