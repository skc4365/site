# Chapter 11 교재 소스 보완 — LangServe

## 관련 링크

- [LangServe 공식 저장소](https://github.com/langchain-ai/langserve)
- [FastAPI 공식 문서](https://fastapi.tiangolo.com/)

## 검토 결과

기존 문서는 `pyproject.toml`만 수록하고 실제 서버·클라이언트 코드가 없습니다. 이 상태로는 LangServe의 목적과 호출 흐름을 실습할 수 없으므로 서버 생성, route 등록, 클라이언트 호출 예제를 추가합니다.

## 설치

```powershell
python -m pip install fastapi uvicorn langserve langchain-openai
```

## 서버 코드

```python
from fastapi import FastAPI
from langchain_core.output_parsers import StrOutputParser
from langchain_core.prompts import ChatPromptTemplate
from langchain_openai import ChatOpenAI
from langserve import add_routes

prompt = ChatPromptTemplate.from_messages(
    [
        ("system", "당신은 제조 설비 점검 도우미입니다."),
        ("human", "{question}"),
    ]
)
chain = prompt | ChatOpenAI(model="gpt-4.1-mini") | StrOutputParser()

app = FastAPI(title="Manufacturing Assistant API", version="1.0.0")
add_routes(app, chain, path="/assistant")


@app.get("/health")
def health() -> dict[str, str]:
    return {"status": "ok"}
```

실행:

```powershell
uvicorn server:app --host 127.0.0.1 --port 8000 --reload
```

## Python 클라이언트

```python
from langserve import RemoteRunnable

client = RemoteRunnable("http://127.0.0.1:8000/assistant/")
answer = client.invoke({"question": "모터 진동 경고 시 점검 순서를 알려주세요."})
print(answer)
```

## 운영 적용 전 확인

- 예제 서버를 인증 없이 외부 네트워크에 공개하지 않습니다.
- 요청 본문 크기, 호출 시간, 동시 요청 수를 제한합니다.
- API 키는 서버에서만 관리하고 클라이언트에 전달하지 않습니다.
- 입력·출력 스키마와 오류 응답을 문서화합니다.
- LangServe가 꼭 필요하지 않다면 FastAPI endpoint에서 서비스 계층을 직접 호출하는 단순 구조도 비교합니다.
- 운영 배포에서는 `--reload`를 제거하고 reverse proxy, TLS, 인증, 로깅을 구성합니다.
