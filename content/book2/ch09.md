# AI 에이전트 활용

## 먼저 보는 구조

```text
요청 → 안전한 도구 선택 → 실행 → 결과 검증
```

## 핵심 개념

- Agentic RAG
- 표 데이터 분석
- 파일·코드 도구 제한

## 기본 코드

```python
safe_tools = [search_documents, analyze_table]
agent = create_agent(model=model, tools=safe_tools)
result = agent.invoke({'messages': messages})
```

## 코드 읽기

1. 입력과 출력 데이터 구조를 확인합니다.
2. 외부 서비스와 비용이 발생하는 지점을 찾습니다.
3. 한 단계씩 따로 실행해 중간 결과를 확인합니다.
4. 실패와 시간 초과를 처리합니다.
