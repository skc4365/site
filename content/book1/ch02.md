# 개발 환경 — 같은 코드를 같은 조건에서 실행하기 위한 준비

## 개념

**개발 환경**은 Python 버전, 가상환경, 패키지 버전, 환경 변수처럼 프로그램 실행 조건을 묶은 것입니다.

## 언제 사용하는가

- 강사와 학습자의 실행 결과를 같게 만들 때
- 프로젝트마다 다른 패키지 버전을 분리할 때
- API Key를 코드 밖에서 안전하게 관리할 때

## 아키텍처

```text
운영체제
  └─ Python 3.12
      └─ 프로젝트 가상환경
          ├─ langchain 1.x
          ├─ 공급자 패키지
          └─ 환경 변수(.env)
```

## 핵심 원리

가상환경은 프로젝트별 Python 실행 파일과 패키지를 격리합니다. `requirements.txt`는 재현할 의존성을 기록하고 `.env`는 배포 환경마다 달라지는 비밀값을 분리합니다.

## 바로 실행하는 명령

```bash
python -m venv .venv
```

Windows PowerShell에서 활성화합니다.

```powershell
.\.venv\Scripts\Activate.ps1
python -m pip install -U pip
pip install -U langchain langchain-openai python-dotenv
python --version
pip show langchain
```

`.env` 예시입니다.

```text
OPENAI_API_KEY=발급받은_API_KEY
OPENAI_MODEL=gpt-4.1-mini
```

Python에서 읽습니다.

```python
import os
from dotenv import load_dotenv

load_dotenv()
model_name = os.getenv("OPENAI_MODEL", "gpt-4.1-mini")
print(model_name)
```

## 요점 정리

1. Python 3.12와 프로젝트 가상환경을 먼저 확인합니다.
2. 패키지는 활성화된 가상환경 안에 설치합니다.
3. 의존성 버전은 파일로 기록해 재현합니다.
4. API Key는 코드와 Git 저장소에 넣지 않습니다.
5. 오류가 나면 Python 경로·버전·가상환경부터 확인합니다.
