# 이메일 자동화 챗봇 — 초안 생성과 실제 발송을 안전하게 분리하는 구조

## 개념

**이메일 자동화 챗봇**은 사용자의 요청을 구조화된 이메일 초안으로 만들고, 사람의 승인을 받은 뒤 발송 도구를 실행합니다.

## 언제 사용하는가

- 반복되는 업무 이메일 초안을 만들 때
- 수신자·제목·본문을 구조화해 다른 시스템에 전달할 때
- 실제 발송 전에 사람의 검토가 필요할 때

## 아키텍처

```text
요청 → LLM 초안 → Schema 검증 → 미리보기 → 사용자 승인
                                                ↓
                                         권한 확인 → 발송 → 기록
```

## 핵심 원리

```text
생성 함수 ≠ 발송 함수
```

초안 생성은 되돌릴 수 있지만 발송은 외부 상태를 바꾸는 Side Effect입니다. 두 단계를 분리해야 테스트 중 실수로 발송되지 않습니다.

| 용어 | 의미 |
|---|---|
| Human-in-the-loop | 실행 전에 사람이 승인·수정·거절 |
| Idempotency | 재시도해도 한 번만 발송되도록 보장 |
| Audit Log | 요청·승인·실행 결과 기록 |

## 바로 실행하는 코드

```bash
pip install -U "pydantic[email]"
```

```python
from pydantic import BaseModel, EmailStr


class EmailDraft(BaseModel):
    to: EmailStr
    subject: str
    body: str


draft = EmailDraft(
    to="student@example.com",
    subject="수업 안내",
    body="내일 오전 9시에 수업을 시작합니다.",
)

print(draft.model_dump())       # 미리보기
approved = input("발송할까요? (yes/no): ") == "yes"
if approved:
    print("승인됨: 실제 프로젝트에서 send_email(draft)를 호출합니다.")
```

## 요점 정리

1. 이메일 생성과 발송은 다른 책임입니다.
2. 수신자·제목·본문은 Schema로 검증합니다.
3. 실제 발송 전 전체 내용을 사용자에게 보여줍니다.
4. 중복 발송 방지를 위한 요청 식별자가 필요합니다.
5. 승인자와 발송 결과를 감사 로그에 남깁니다.
