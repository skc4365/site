# 이메일 업무 자동화 챗봇

## 먼저 보는 구조

```text
요청 → 이메일 초안 → 사용자 확인 → 발송
```

## 핵심 개념

- 구조화된 이메일 초안
- 승인 단계
- 쓰기 도구 안전성

## 기본 코드

```python
draft = EmailDraft(to=to, subject=subject, body=body)
if approved:
    send_email(draft)
```

## 코드 읽기

1. 입력이 무엇인지 찾습니다.
2. 어떤 객체가 실제 작업을 수행하는지 확인합니다.
3. 반환값의 타입과 내용을 출력합니다.
4. 작은 입력으로 먼저 실행합니다.
