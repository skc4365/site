# 임베딩(Embedding) — 텍스트 의미를 비교 가능한 숫자 벡터로 표현하는 기술

## 개념

**임베딩**은 텍스트의 의미적 특징을 실수 배열인 Vector로 변환합니다. 의미가 비슷한 텍스트는 벡터 공간에서 가깝게 배치됩니다.

## 언제 사용하는가

- 정확한 단어가 달라도 의미가 비슷한 문서를 찾을 때
- 문서 군집·중복 탐지·추천을 수행할 때
- Vector Store에 검색용 표현을 저장할 때

## 아키텍처

```text
문서 → Embedding Model → 문서 Vector ─┐
질문 → 같은 Model ─────> 질문 Vector ─┴─> Similarity
```

## 핵심 원리

대표적인 Cosine Similarity는 벡터 방향을 비교합니다.

```text
cosine(q, d) = (q · d) / (||q|| × ||d||)
```

문서와 질문은 같은 임베딩 모델을 사용해야 합니다. 모델을 바꾸면 벡터 공간도 달라지므로 문서를 다시 임베딩합니다.

## 바로 실행하는 코드

```bash
pip install -U langchain-openai
```

`OPENAI_API_KEY` 환경 변수를 설정한 뒤 실행합니다.

```python
from langchain_openai import OpenAIEmbeddings

embeddings = OpenAIEmbeddings(model="text-embedding-3-small")
query_vector = embeddings.embed_query("RAG 검색")

print(type(query_vector))
print("차원:", len(query_vector))
print("앞 5개 값:", query_vector[:5])
```

## 요점 정리

1. 임베딩은 답변이 아니라 숫자 Vector를 만듭니다.
2. 문서와 질문에 같은 모델을 사용합니다.
3. 유사도가 높다는 사실이 문장 내용의 진실을 보장하지는 않습니다.
4. 코드·숫자·고유명사에는 키워드 검색을 함께 사용할 수 있습니다.
5. 모델 변경 시 인덱스를 다시 구축합니다.
