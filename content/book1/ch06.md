# 출력 파서와 구조화 출력 — 모델 응답을 검증 가능한 데이터로 변환하는 방법

## 개념

**출력 파싱**은 모델 응답을 문자열·dict·Pydantic 객체처럼 프로그램이 사용할 형태로 바꾸는 과정입니다.

## 언제 사용하는가

- 응답 문자열만 화면에 표시할 때
- 결과를 DB 저장·API 호출·표 출력에 사용할 때
- 필드 타입과 값 범위를 검증해야 할 때

## 아키텍처

```text
자유 형식 응답 → Parser → Python 데이터
스키마 요청 ───> Model ──> 검증된 Pydantic 객체
```

## 핵심 원리

```text
Schema = 필드 이름 + 자료형 + 필수 여부 + 값 제약
```

`StrOutputParser`는 `AIMessage.content`를 문자열로 꺼냅니다. 구조화 출력은 모델이 정해진 스키마로 응답하게 하고 Pydantic이 결과를 검증합니다.

## 바로 실행하는 코드

```bash
pip install -U langchain-openai pydantic
```

`OPENAI_API_KEY` 환경 변수를 설정한 뒤 실행합니다.

```python
from typing import Literal
from langchain_openai import ChatOpenAI
from pydantic import BaseModel, Field


class Review(BaseModel):
    sentiment: Literal["긍정", "부정"]
    confidence: float = Field(ge=0, le=1)


model = ChatOpenAI(model="gpt-4.1-mini", temperature=0)
structured = model.with_structured_output(Review)
result = structured.invoke("배송이 빠르고 제품도 좋았습니다.")

print(result.sentiment, result.confidence)
```

## 요점 정리

1. 화면용 문장에는 문자열 파서가 적합합니다.
2. 후속 프로그램이 사용할 결과에는 구조화 출력이 적합합니다.
3. Schema는 모델과 애플리케이션 사이의 데이터 계약입니다.
4. Pydantic은 타입과 범위를 실행 중 검증합니다.
5. 파싱 실패를 정상적인 오류 흐름으로 처리해야 합니다.
