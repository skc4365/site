## 검토 결과

기존 문서는 범용 기본값인 Recursive 분할만 포함합니다. 토큰 제한과 Markdown·HTML·JSON·코드의 구조를 보존하려면 문서 유형별 분할기도 함께 알아야 합니다.

## 원본 예제 지도

| 번호 | 분할기 | 권장 상황 |
| --- | --- | --- |
| 01 | Character | 구분자가 명확한 단순 텍스트 |
| 02 | RecursiveCharacter | 일반 문서의 기본 선택 |
| 03 | Token | 모델 컨텍스트 한도 관리 |
| 04 | SemanticChunker | 의미 변화 기준 분할 실험 |
| 05 | CodeSplitter | 함수·클래스 구조 보존 |
| 06 | MarkdownHeader | Markdown 제목 계층 보존 |
| 07 | HTMLHeader | HTML 제목 구조 보존 |
| 08 | RecursiveJson | 중첩 JSON 구조 보존 |

## 1. 범용 Recursive 분할

```python
from langchain_text_splitters import RecursiveCharacterTextSplitter

splitter = RecursiveCharacterTextSplitter(
    chunk_size=500,
    chunk_overlap=80,
    separators=["\n\n", "\n", ". ", " ", ""],
)
chunks = splitter.create_documents(["설비 매뉴얼 본문을 여기에 입력합니다."])
print(len(chunks), chunks[0].page_content)
```

## 2. 토큰 기준 분할

```python
from langchain_text_splitters import CharacterTextSplitter

splitter = CharacterTextSplitter.from_tiktoken_encoder(
    encoding_name="cl100k_base",
    chunk_size=300,
    chunk_overlap=40,
)
chunks = splitter.split_text("긴 점검 기록을 여기에 입력합니다.")
```

## 3. Markdown 구조 보존

```python
from langchain_text_splitters import MarkdownHeaderTextSplitter

headers = [("#", "chapter"), ("##", "section"), ("###", "topic")]
splitter = MarkdownHeaderTextSplitter(headers_to_split_on=headers)
documents = splitter.split_text("# 안전\n## 정지 절차\n비상 정지 버튼을 누릅니다.")
print(documents[0].metadata)
```

## 평가 기준

- 질문의 정답이 한 청크 안에 유지되는지 확인합니다.
- 청크가 너무 작아 문맥이 끊기거나 너무 커서 잡음이 늘지 않는지 비교합니다.
- `chunk_size`와 `chunk_overlap`을 고정값으로 믿지 말고 검색 평가 데이터로 조정합니다.
- 코드와 구조 문서는 범용 문자 분할보다 전용 분할기를 우선합니다.
