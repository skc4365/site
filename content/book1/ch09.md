# 문서 로더(Document Loader) — 다양한 원천을 공통 Document로 변환하는 기술

## 개념

**Document Loader**는 PDF, CSV, Web 같은 데이터를 읽어 LangChain의 `Document` 객체로 변환합니다.

## 언제 사용하는가

- 서로 다른 파일 형식을 같은 RAG 파이프라인에 넣을 때
- 검색 결과에 파일명·페이지·URL 출처를 남길 때
- 큰 데이터를 순차적으로 로딩할 때

## 아키텍처

```text
PDF·CSV·Web·DB → Loader → Document(page_content, metadata)
```

## 핵심 원리

| 필드 | 역할 |
|---|---|
| `page_content` | 검색·생성에 사용할 본문 |
| `metadata` | 출처 표시와 필터링 정보 |

`load()`는 전체를 한 번에 읽고 `lazy_load()`는 문서를 순차적으로 읽습니다. 스캔 PDF는 이미지이므로 OCR이 필요할 수 있습니다.

## 바로 실행하는 코드

```bash
pip install -U langchain-core
```

```python
from langchain_core.documents import Document

document = Document(
    page_content="append()는 리스트 끝에 값을 추가한다.",
    metadata={"source": "python-guide.pdf", "page": 12},
)

print(document.page_content)
print(document.metadata)
```

## 요점 정리

1. Loader는 원천 데이터를 공통 `Document`로 정규화합니다.
2. 본문은 `page_content`, 출처는 `metadata`에 둡니다.
3. 대용량 데이터에는 `lazy_load()`를 검토합니다.
4. 로딩 후 빈 문서·깨진 글자·중복을 확인합니다.
5. 인덱싱 전에 문서 접근 권한을 점검합니다.
