# 모델

## 먼저 보는 구조

```text
공통 인터페이스 → OpenAI·Ollama·다른 모델
```

## 핵심 개념

- Chat Model 인터페이스
- 모델 설정
- 응답 metadata

## 기본 코드

```python
model = ChatOpenAI(model=os.getenv('OPENAI_MODEL', 'gpt-4.1-mini'), temperature=0)
response = model.invoke('안녕하세요')
```

## 코드 읽기

1. 입력이 무엇인지 찾습니다.
2. 어떤 객체가 실제 작업을 수행하는지 확인합니다.
3. 반환값의 타입과 내용을 출력합니다.
4. 작은 입력으로 먼저 실행합니다.

## 확인하기
