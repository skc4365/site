# Chat Model — 메시지를 받아 답변·도구 호출·구조화 결과를 생성하는 모델

## 개념

**Chat Model**은 메시지 목록을 입력받아 `AIMessage`를 반환하는 LangChain 모델 인터페이스입니다.

## 언제 사용하는가

- 일반 답변·요약·분류를 생성할 때
- Tool Calling과 구조화 출력을 사용할 때
- 같은 애플리케이션에서 공급자 모델을 교체할 때

## 아키텍처

```text
LangChain 공통 인터페이스
  ├─ ChatOpenAI
  ├─ ChatAnthropic
  └─ ChatOllama
       ↓
invoke·batch·stream → AIMessage
```

## 핵심 원리

공통 호출 방식이 같아도 모델별 Context 한도, Tool Calling, 멀티모달, 비용과 지연 시간은 다릅니다.

| 기준 | 확인 내용 |
|---|---|
| 기능 | Tool·구조화 출력·이미지 지원 |
| 품질 | 실제 평가셋 성공률 |
| 운영 | 비용·지연·Rate Limit |
| 정책 | 데이터 저장·지역·보안 |

## 바로 실행하는 코드

```bash
pip install -U langchain-openai
```

`OPENAI_API_KEY` 환경 변수를 설정한 뒤 실행합니다.

```python
from langchain_openai import ChatOpenAI

model = ChatOpenAI(model="gpt-4.1-mini", temperature=0)
response = model.invoke("Python의 특징을 한 문장으로 설명해줘.")

print(response.content)
print(response.response_metadata)
```

## 요점 정리

1. Chat Model은 메시지를 입력받아 메시지를 반환합니다.
2. 공급자가 달라도 공통 `invoke()` 인터페이스를 사용합니다.
3. 공통 인터페이스가 동일한 기능을 보장하지는 않습니다.
4. 모델은 품질·기능·비용·지연 시간으로 평가합니다.
5. 모델 변경 후에는 같은 평가셋으로 회귀 테스트합니다.
