## ZIP 노트북 실제 코드 셀

아래는 제공된 ZIP에서 직접 추출한 핵심 코드입니다. 원본 0.3 계열 코드이므로 먼저 구조를 읽고, 다음 절의 1.x 기준으로 수정합니다.

```python
from langchain_core.prompts import ChatPromptTemplate, load_prompt

# ChatPromptTemplate 생성
prompt = ChatPromptTemplate.from_messages(
    [
        ("system", "You are a helpful assistant"),
        ("user", "{country}의 수도는 어디인가요?"),
    ]
)
prompt
```

### 이 코드에서 바꿀 부분

- 원본의 import 경로와 호출 API가 1.x에서도 유지되는지 장별 변환 코드와 비교합니다.

## Python 3.12·LangChain 1.x 적용

Runnable의 invoke·batch·stream 인터페이스와 공급자별 통합 패키지를 사용합니다.

```python
chain = prompt | model | StrOutputParser()
result = chain.invoke({'question': question})
```

## 원본을 읽는 순서

1. import와 초기 설정을 찾습니다.
2. 입력 데이터가 만들어지는 셀을 확인합니다.
3. 핵심 객체의 반환 타입을 출력합니다.
4. 위 1.x 패턴으로 바꾸고 작은 입력부터 실행합니다.
