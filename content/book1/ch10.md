# 텍스트 분할(Text Splitting) — 긴 문서를 검색 가능한 Chunk로 나누는 기술

## 개념

**텍스트 분할**은 긴 문서를 검색과 모델 Context에 적합한 작은 문서 조각인 Chunk로 나누는 과정입니다.

## 언제 사용하는가

- 문서가 임베딩·모델 입력 한도보다 길 때
- 질문과 직접 관련된 일부 문단만 검색할 때
- 제목·문단·코드 구조를 유지해야 할 때

## 아키텍처

```text
긴 Document → Splitter → 겹치는 Chunk 목록 → Embedding
```

## 핵심 원리

```text
작은 Chunk: 검색 정밀도↑, 주변 문맥↓, 조각 수↑
큰 Chunk:   주변 문맥↑, 잡음·토큰 비용↑
```

`chunk_overlap`은 경계의 문맥을 보존하지만 중복 저장량을 늘립니다. 고정 정답 크기보다 실제 질문으로 평가해야 합니다.

## 바로 실행하는 코드

```bash
pip install -U langchain-text-splitters
```

```python
from langchain_text_splitters import RecursiveCharacterTextSplitter

text = "첫 문단입니다.\n\n두 번째 문단은 더 긴 설명을 포함합니다.\n\n세 번째 문단입니다."
splitter = RecursiveCharacterTextSplitter(chunk_size=30, chunk_overlap=5)

for index, chunk in enumerate(splitter.split_text(text), 1):
    print(index, repr(chunk))
```

## 요점 정리

1. Chunk는 RAG 검색의 기본 단위입니다.
2. 너무 작으면 문맥이 끊기고 너무 크면 잡음이 늘어납니다.
3. Overlap은 경계 문맥과 저장 비용을 함께 늘립니다.
4. Markdown·HTML·코드는 구조 기반 분할을 우선 검토합니다.
5. 분할 후에도 출처 metadata를 유지합니다.
