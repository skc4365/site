# RAG 이해하기

## 먼저 보는 구조

```text
질문 → 검색 → 관련 문서 → LLM → 근거 있는 답변
```

## 핵심 개념

- RAG가 필요한 이유
- LLM 내부 지식과 외부 문서의 차이
- 검색 결과를 근거로 답변하는 흐름

## 기본 코드

```python
docs = retriever.invoke(question)
context = '\n\n'.join(doc.page_content for doc in docs)
answer = rag_chain.invoke({'question': question, 'context': context})
```

## 코드 읽기

1. 입력이 무엇인지 찾습니다.
2. 어떤 객체가 실제 작업을 수행하는지 확인합니다.
3. 반환값의 타입과 내용을 출력합니다.
4. 작은 입력으로 먼저 실행합니다.

## 확인하기

- 실패할 수 있는 지점은 어디인가요?
