# Streamlit 챗봇 — Python 모델 호출을 대화형 웹 화면으로 제공하는 방법

## 개념

**Streamlit 챗봇**은 `chat_input`, `chat_message`, `session_state`를 사용해 Python AI 기능을 웹 대화 화면으로 구성합니다.

## 언제 사용하는가

- RAG·LLM 기능을 빠르게 시연할 때
- Python 중심의 내부 업무용 챗봇을 만들 때
- 대화 기록과 스트리밍 응답을 화면에 표시할 때

## 아키텍처

```text
브라우저 입력 → Streamlit 스크립트 재실행 → Model → 화면 출력
                      │
                      └─ session_state에 대화 유지
```

## 핵심 원리

Streamlit은 사용자 조작마다 스크립트를 위에서 아래로 다시 실행합니다.

| 기능 | 역할 |
|---|---|
| `st.chat_input` | 사용자 질문 입력 |
| `st.chat_message` | 역할별 메시지 표시 |
| `st.session_state` | 재실행 사이의 사용자 상태 |
| `st.cache_resource` | 모델·DB 객체 재사용 |

## 바로 실행하는 코드

```bash
pip install -U streamlit
```

다음 코드를 `app.py`로 저장합니다.

```python
import streamlit as st

st.title("간단한 챗봇")

if "messages" not in st.session_state:
    st.session_state.messages = []

for message in st.session_state.messages:
    st.chat_message(message["role"]).write(message["content"])

if question := st.chat_input("질문을 입력하세요"):
    st.session_state.messages.append({"role": "user", "content": question})
    answer = f"입력한 질문: {question}"
    st.session_state.messages.append({"role": "assistant", "content": answer})
    st.rerun()
```

```bash
streamlit run app.py
```

## 요점 정리

1. Streamlit은 입력이 바뀔 때 스크립트를 다시 실행합니다.
2. 대화 기록은 `session_state`에 저장합니다.
3. 무거운 모델과 저장소는 `cache_resource`로 재사용합니다.
4. UI와 AI 서비스 로직을 분리합니다.
5. API Key와 내부 오류 전체를 화면에 노출하지 않습니다.
