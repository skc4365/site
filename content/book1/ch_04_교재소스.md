## ZIP 노트북 실제 코드 셀

아래는 제공된 ZIP에서 직접 추출한 핵심 코드입니다. 원본 0.3 계열 코드이므로 먼저 구조를 읽고, 다음 절의 1.x 기준으로 수정합니다.

```python
from langchain_teddynote.messages import stream_response  # 스트리밍 출력
from langchain_core.prompts import PromptTemplate

# --- 다음 원본 코드 셀 ---

# template 정의
template = "{country}의 수도는 어디인가요?"

# from_template 메소드를 이용하여 PromptTemplate 객체 생성
prompt_template = PromptTemplate.from_template(template)
prompt_template

# --- 다음 원본 코드 셀 ---

from langchain_openai import ChatOpenAI

model = ChatOpenAI(
    model="gpt-4.1-nano",
    temperature=0.1,
)

# --- 다음 원본 코드 셀 ---

# prompt 를 PromptTemplate 객체로 생성합니다.
prompt = PromptTemplate.from_template("{topic} 에 대해 쉽게 설명해주세요.")

model = ChatOpenAI(model="gpt-4.1-nano", temperature=0.1)

chain = prompt | model

# --- 다음 원본 코드 셀 ---

# prompt 객체와 model 객체를 파이프(|) 연산자로 연결하고 invoke 메서드를 사용하여 input을 전달합니다.
# 이를 통해 AI 모델이 생성한 메시지를 반환합니다.
chain.invoke(input)
```

### 이 코드에서 바꿀 부분

- `langchain_teddynote` 출력·추적 도우미는 필수 의존성에서 제외하고 표준 callback 또는 LangSmith 설정으로 교체합니다.

## Python 3.12·LangChain 1.x 적용

Runnable의 invoke·batch·stream 인터페이스와 공급자별 통합 패키지를 사용합니다.

```python
chain = prompt | model | StrOutputParser()
result = chain.invoke({'question': question})
```
