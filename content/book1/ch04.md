# LangChain — Prompt·Model·Tool을 공통 방식으로 연결하는 프레임워크

## 개념

**LangChain**은 LLM 애플리케이션의 Prompt, Model, Parser, Retriever, Tool을 공통 인터페이스로 조합하게 합니다.

## 언제 사용하는가

- 여러 AI 구성요소를 반복 가능한 흐름으로 연결할 때
- 모델 공급자를 바꾸면서 애플리케이션 구조를 유지할 때
- 단일 호출을 Chain·RAG·Agent로 확장할 때

## 아키텍처

```text
입력 → Prompt → Model → Parser → 출력
         └──── 공통 Runnable 인터페이스 ────┘
```

## 핵심 원리

```text
chain = prompt | model | parser
```

`|`는 앞 단계 출력을 다음 단계 입력으로 전달합니다.

| 메서드 | 용도 |
|---|---|
| `invoke()` | 입력 한 건 실행 |
| `batch()` | 여러 독립 입력 실행 |
| `stream()` | 생성 결과를 순차 전달 |

## 바로 실행하는 코드

```bash
pip install -U langchain langchain-openai
```

`OPENAI_API_KEY` 환경 변수를 설정한 뒤 실행합니다.

```python
from langchain_core.output_parsers import StrOutputParser
from langchain_core.prompts import ChatPromptTemplate
from langchain_openai import ChatOpenAI

prompt = ChatPromptTemplate.from_template("{topic}을 한 문장으로 설명하세요.")
model = ChatOpenAI(model="gpt-4.1-mini", temperature=0)
chain = prompt | model | StrOutputParser()

print(chain.invoke({"topic": "LangChain"}))
```

오류가 나면 `prompt.invoke()`처럼 각 단계를 따로 실행해 출력 타입을 확인합니다.

## 요점 정리

1. LangChain은 AI 구성요소를 연결하는 프레임워크입니다.
2. Runnable은 입력을 출력으로 바꾸는 공통 실행 규약입니다.
3. `|`는 Runnable을 순서대로 연결합니다.
4. `invoke`, `batch`, `stream`은 실행 방식이 다릅니다.
5. 복잡한 분기와 상태가 필요하면 LangGraph를 검토합니다.
