## 공통 인터페이스

```python
from langchain_openai import OpenAIEmbeddings

embeddings = OpenAIEmbeddings(model="text-embedding-3-small")
document_vectors = embeddings.embed_documents(["모터 진동 증가", "윤활유 교체"])
query_vector = embeddings.embed_query("진동이 커졌습니다")

print(len(document_vectors), len(query_vector))
```

## 로컬 Hugging Face 모델

```python
from langchain_huggingface import HuggingFaceEmbeddings

embeddings = HuggingFaceEmbeddings(
    model_name="sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2"
)
vector = embeddings.embed_query("프레스 설비 이상 진동")
print(len(vector))
```

## Ollama 임베딩

```python
from langchain_ollama import OllamaEmbeddings

embeddings = OllamaEmbeddings(model="nomic-embed-text")
vector = embeddings.embed_query("베어링 온도 상승")
```

## 선택·평가 기준

- 쿼리와 문서에 동일한 임베딩 모델 및 버전을 사용합니다.
- 모델을 바꾸면 기존 벡터를 모두 다시 생성합니다.
- 한국어와 제조 용어가 포함된 실제 질문으로 검색 정확도를 평가합니다.
- 정확도뿐 아니라 차원 수, 처리 시간, API 비용, 데이터 외부 전송 여부를 비교합니다.
- 대량 문서 재처리 시 임베딩 캐시와 배치 처리를 검토합니다.
