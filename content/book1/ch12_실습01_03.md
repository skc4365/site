# VectorStore 실습

임베딩 벡터, 원문, 메타데이터를 저장하고 질문과 가까운 문서를 찾는 **VectorStore**. RAG에서 문서 인덱싱과 검색을 담당하는 핵심 계층.

## 핵심 구조

```text
Document ─> Embedding ─> VectorStore Index
Query ────> Embedding ─> Similarity Search ─> 상위 K개 Document
```

| 항목 | 핵심 |
| --- | --- |
| Index | 가까운 벡터를 빠르게 찾는 자료 구조 |
| `k` | 반환할 검색 결과 수 |
| Filter | 메타데이터 기반 검색 범위 제한 |
| Score | 저장소와 거리 함수별 유사도·거리 값 |
| Persistence | 재실행 후 데이터 유지 방식 |
| Namespace | 하나의 인덱스 안에서 데이터 논리 분리 |

- 문서와 질문에 동일한 임베딩 모델·버전·차원 사용
- 모델 또는 차원 변경 시 새 인덱스 생성과 전체 재임베딩
- 문서 ID와 원본 출처를 메타데이터에 저장
- `k` 증가 시 Recall과 검색 잡음 동시 증가
- 저장소별 점수 범위와 정렬 방향 확인
- 원문 저장소, 백업, 접근 권한의 별도 설계

<summary>공통 예제 데이터와 환경 설정</summary>

```bash
pip install -U langchain-core langchain-openai
```

환경변수 설정:


```python
from langchain_core.documents import Document
from langchain_openai import OpenAIEmbeddings

embeddings = OpenAIEmbeddings(
    model="text-embedding-3-small",
    dimensions=1024,
)

documents = [
    Document(
        page_content="모터 진동이 증가하면 베어링과 축 정렬을 점검합니다.",
        metadata={
            "document_id": "M-001",
            "category": "maintenance",
            "source": "motor-guide.md",
        },
    ),
    Document(
        page_content="설비 온도가 80도를 넘으면 냉각 계통을 확인합니다.",
        metadata={
            "document_id": "M-002",
            "category": "safety",
            "source": "safety-guide.md",
        },
    ),
    Document(
        page_content="윤활유는 6개월 또는 2,000시간마다 교체합니다.",
        metadata={
            "document_id": "M-003",
            "category": "maintenance",
            "source": "lubrication-guide.md",
        },
    ),
]

ids = [document.metadata["document_id"] for document in documents]
```

## 1. Chroma

로컬 메모리, 로컬 영속 저장, 별도 서버, Chroma Cloud를 지원하는 오픈소스 벡터 데이터베이스.

- 패키지: `langchain-chroma`
- 적합: 빠른 개발, 로컬 실습, 중소 규모 영속 저장
- 영속화: `persist_directory`
- 주요 기능: 추가, 수정, 삭제, 메타데이터 필터, MMR 검색
- 장점: 간단한 설치와 개발 편의성
- 운영 검토: 동시성, 백업, 서버 구성, 데이터 규모

<details markdown="1">
<summary>예제 코드: Chroma 저장·검색·복원</summary>

```bash
pip install -U "langchain-chroma>=0.1.2" langchain-openai
```

로컬 영속 컬렉션 생성:

```python
from langchain_chroma import Chroma

vector_store = Chroma(
    collection_name="equipment_manual",
    embedding_function=embeddings,
    persist_directory="./data/chroma_db",
)

vector_store.add_documents(
    documents=documents,
    ids=ids,
)
```

메타데이터 필터 검색:

```python
results = vector_store.similarity_search(
    query="진동이 커졌을 때 무엇을 점검해야 하나요?",
    k=2,
    filter={"category": "maintenance"},
)

for document in results:
    print(document.metadata)
    print(document.page_content)
```

점수와 함께 검색:

```python
results_with_score = vector_store.similarity_search_with_score(
    query="온도 기준 초과",
    k=2,
)

for document, score in results_with_score:
    print(f"score={score:.4f}", document.metadata["document_id"])
```

기존 로컬 컬렉션 다시 연결:

```python
loaded_store = Chroma(
    collection_name="equipment_manual",
    embedding_function=embeddings,
    persist_directory="./data/chroma_db",
)

results = loaded_store.similarity_search("윤활유 교체 주기", k=1)
print(results[0].page_content)
```

MMR Retriever 변환:

```python
retriever = loaded_store.as_retriever(
    search_type="mmr",
    search_kwargs={"k": 2, "fetch_k": 5},
)
documents_found = retriever.invoke("설비 예방 정비")
```

## 2. FAISS

Meta가 개발한 고성능 벡터 유사도 검색 라이브러리. 서버형 데이터베이스가 아닌 **로컬 인덱스 라이브러리**.

- 패키지: `faiss-cpu`, `langchain-community`
- 적합: 로컬 검색, 프로토타입, 대량 벡터의 빠른 근접 검색
- 영속화: `save_local()`과 `load_local()`
- 장점: 빠른 검색과 다양한 인덱스 알고리즘
- 운영 검토: 동시 쓰기, 백업, 메타데이터 저장, 서비스 계층
- 보안: 신뢰할 수 없는 pickle 기반 인덱스 복원 금지

<details markdown="1">
<summary>예제 코드: FAISS 생성·검색·저장·복원</summary>

```bash
pip install -U faiss-cpu langchain-community langchain-openai
```

인덱스 생성과 검색:

```python
from langchain_community.vectorstores import FAISS

vector_store = FAISS.from_documents(
    documents=documents,
    embedding=embeddings,
    ids=ids,
)

results = vector_store.similarity_search(
    query="베어링 이상을 확인하는 방법",
    k=2,
    filter={"category": "maintenance"},
)

for document in results:
    print(document.metadata["document_id"], document.page_content)
```

로컬 저장:

```python
vector_store.save_local("./data/faiss_equipment_index")
```

신뢰할 수 있는 인덱스 복원:

```python
loaded_store = FAISS.load_local(
    "./data/faiss_equipment_index",
    embeddings,
    allow_dangerous_deserialization=True,
)

results = loaded_store.similarity_search("냉각 계통 점검", k=1)
print(results[0].page_content)
```

> `allow_dangerous_deserialization=True`는 pickle 역직렬화 허용 옵션. 직접 생성하고 무결성을 확인한 인덱스에만 사용.

점수와 함께 검색:

```python
results_with_score = loaded_store.similarity_search_with_score(
    "윤활유 교체",
    k=2,
)

for document, score in results_with_score:
    print(f"score={score:.4f}", document.metadata["document_id"])
```

기본 FAISS 거리 점수는 낮을수록 가까운 경우가 많지만, 인덱스와 거리 전략에 따라 의미가 달라질 수 있으므로 설정별 확인 필수.

</details>

## 3. Pinecone

인덱스 운영과 확장을 서비스로 제공하는 관리형 벡터 데이터베이스.

- 패키지: `langchain-pinecone`
- 인증: `PINECONE_API_KEY`
- 적합: 운영 서비스, 다중 사용자, 확장 가능한 관리형 검색
- 데이터 분리: Index와 Namespace
- 장점: 서버 운영 부담 감소, 확장성과 가용성
- 운영 검토: 비용, 리전, 지연 시간, 외부 전송 정책
- 필수 조건: Pinecone 인덱스 차원과 임베딩 벡터 차원의 일치

<details markdown="1">
<summary>예제 코드: Pinecone 인덱스 생성·검색</summary>

```bash
pip install -U langchain-pinecone langchain-openai
```

환경변수 설정:

```bash
# macOS/Linux
export PINECONE_API_KEY="발급받은_API_키"

# Windows PowerShell
$env:PINECONE_API_KEY="발급받은_API_키"
```

1024차원 Serverless 인덱스 준비:

```python
import os
from time import sleep

from pinecone import Pinecone, ServerlessSpec

index_name = "equipment-manual"
pc = Pinecone(api_key=os.environ["PINECONE_API_KEY"])

if not pc.has_index(index_name):
    pc.create_index(
        name=index_name,
        vector_type="dense",
        dimension=1024,
        metric="cosine",
        spec=ServerlessSpec(
            cloud="aws",
            region="us-east-1",
        ),
    )

while not pc.describe_index(index_name).status["ready"]:
    sleep(1)

index = pc.Index(index_name)
```

LangChain 연결과 문서 추가:

```python
from langchain_pinecone import PineconeVectorStore

vector_store = PineconeVectorStore(
    index=index,
    embedding=embeddings,
    namespace="equipment-v1",
)

vector_store.add_documents(
    documents=documents,
    ids=ids,
)
```

메타데이터 필터 검색:

```python
results = vector_store.similarity_search(
    query="정기 교체가 필요한 항목",
    k=2,
    filter={"category": "maintenance"},
)

for document in results:
    print(document.metadata)
    print(document.page_content)
```

Retriever 변환:

```python
retriever = vector_store.as_retriever(
    search_type="similarity_score_threshold",
    search_kwargs={
        "k": 3,
        "score_threshold": 0.5,
    },
)
documents_found = retriever.invoke("설비 안전 기준")
```

기존 인덱스 연결 시 동일한 `index_name`, `namespace`, 임베딩 모델, 차원 설정 사용.

</details>

## VectorStore 선택 가이드

| 저장소 | 실행 방식 | 적합한 상황 | 주요 고려 사항 |
| --- | --- | --- | --- |
| Chroma | 로컬·서버·클라우드 | 빠른 개발과 간단한 영속 저장 | 운영 규모, 백업, 동시성 |
| FAISS | 로컬 라이브러리 | 빠른 로컬 유사도 검색 | 서비스·메타데이터 계층 별도 설계 |
| Pinecone | 관리형 클라우드 | 확장형 운영 서비스 | 비용, 리전, 외부 전송 |

## 공통 검색 패턴

```python
# 유사도 검색
documents_found = vector_store.similarity_search(query, k=3)

# 점수 포함 검색
results = vector_store.similarity_search_with_score(query, k=3)

# Retriever 인터페이스
retriever = vector_store.as_retriever(search_kwargs={"k": 3})
documents_found = retriever.invoke(query)
```

## 최종 점검

- 임베딩 모델·버전·차원 기록
- 안정적인 문서 ID와 원본 출처 메타데이터
- 중복 삽입 방지와 갱신·삭제 정책
- 실제 질문 기반 `k`, Filter, Score Threshold 평가
- 인덱스 백업과 복원 테스트
- 개인정보·기밀정보의 저장 위치 확인
- 원본 문서의 별도 보존
