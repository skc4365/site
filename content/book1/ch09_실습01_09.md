# 문서 로더 실습

파일, 웹 페이지, 데이터베이스 등의 데이터를 LangChain의 `Document` 객체로 변환하는 문서 로더(Document Loader). 주요 로더와 대용량 문서 처리 실습.

> **실습 전 확인**
>
> 기본 패키지 설치. 일부 로더는 별도 API 키 또는 시스템 패키지 필요.

<details markdown="1">
<summary>예시 코드: 기본 패키지 설치</summary>

```bash
pip install -U langchain langchain-community pypdf pandas beautifulsoup4 lxml
```

</details>

## 1. 문서 로더의 구조 이해 - Document

원본 데이터를 `Document` 객체 목록으로 변환하는 LangChain 문서 로더. 본문용 `page_content`와 출처·페이지 번호용 `metadata`로 구성.

- `load()`: 모든 문서의 일괄 메모리 적재
- `lazy_load()`: 문서별 이터레이터 반환
- `aload()`, `alazy_load()`: 비동기 로드

<details markdown="1">
<summary>예시 코드: Document 생성과 구조 확인</summary>

```python
from langchain_core.documents import Document

document = Document(
    page_content="LangChain 문서 로더는 다양한 데이터를 공통 형식으로 변환합니다.",
    metadata={
        "source": "example.txt",
        "page": 1,
        "category": "tutorial",
    },
)

print(document.page_content)
print(document.metadata)
print(document.metadata["source"])
```

</details>

<details markdown="1">
<summary>예시 코드: 사용자 정의 문서 로더</summary>

```python
from collections.abc import Iterator

from langchain_core.document_loaders import BaseLoader
from langchain_core.documents import Document


class LineLoader(BaseLoader):
    """텍스트 파일을 한 줄씩 Document로 변환하는 간단한 로더입니다."""

    def __init__(self, file_path: str) -> None:
        self.file_path = file_path

    def lazy_load(self) -> Iterator[Document]:
        with open(self.file_path, encoding="utf-8") as file:
            for line_number, line in enumerate(file, start=1):
                text = line.strip()
                if not text:
                    continue

                yield Document(
                    page_content=text,
                    metadata={
                        "source": self.file_path,
                        "line": line_number,
                    },
                )


loader = LineLoader("data/example.txt")

for document in loader.lazy_load():
    print(document.metadata, document.page_content)
```

</details>

## 2. PyPDFLoader

PDF를 페이지 단위 `Document`로 변환하는 `PyPDFLoader`. 이미지형 PDF는 OCR 또는 문서 파싱 서비스 필요.

<details markdown="1">
<summary>예시 코드: PDF 불러오기</summary>

```python
from langchain_community.document_loaders import PyPDFLoader

loader = PyPDFLoader("data/sample.pdf")
documents = loader.load()

print(f"문서 수: {len(documents)}")
print(documents[0].page_content[:500])
print(documents[0].metadata)
```

</details>

<details markdown="1">
<summary>예시 코드: PDF를 지연 로드하기</summary>

```python
from langchain_community.document_loaders import PyPDFLoader

loader = PyPDFLoader("data/sample.pdf")

for document in loader.lazy_load():
    page = document.metadata.get("page")
    print(f"page={page}, length={len(document.page_content)}")
```

</details>

## 3. HWPLoader

OLE 구조와 압축 텍스트 스트림으로 구성된 HWP 파일. `.hwp` 본문 추출용 사용자 정의 로더 예제. 암호화·배포용 HWP는 별도 처리 필요.

<details markdown="1">
<summary>예시 코드: HWP 로더 구현 및 사용</summary>

```bash
pip install -U olefile
```

```python
import re
import struct
import zlib
from collections.abc import Iterator
from pathlib import Path

import olefile
from langchain_core.document_loaders import BaseLoader
from langchain_core.documents import Document


class HWPLoader(BaseLoader):
    """HWP 5.x 파일에서 본문 텍스트를 추출합니다."""

    FILE_HEADER = "FileHeader"
    HWP_SUMMARY = "\u0005HwpSummaryInformation"

    def __init__(self, file_path: str) -> None:
        self.file_path = Path(file_path)

    def _is_valid_hwp(self, ole: olefile.OleFileIO) -> bool:
        streams = {"/".join(item) for item in ole.listdir()}
        return self.FILE_HEADER in streams and self.HWP_SUMMARY in streams

    def _is_compressed(self, ole: olefile.OleFileIO) -> bool:
        header = ole.openstream(self.FILE_HEADER).read()
        return bool(header[36] & 1)

    @staticmethod
    def _extract_text(section: bytes) -> str:
        texts: list[str] = []
        position = 0

        while position + 4 <= len(section):
            header = struct.unpack_from("<I", section, position)[0]
            record_type = header & 0x3FF
            record_length = (header >> 20) & 0xFFF
            position += 4

            if record_length == 0xFFF:
                if position + 4 > len(section):
                    break
                record_length = struct.unpack_from("<I", section, position)[0]
                position += 4

            payload = section[position : position + record_length]
            position += record_length

            # HWPTAG_PARA_TEXT의 태그 ID는 67입니다.
            if record_type == 67:
                text = payload.decode("utf-16-le", errors="ignore")
                text = re.sub(r"[\x00-\x08\x0b-\x1f]", "", text)
                texts.append(text)

        return "\n".join(texts)

    def lazy_load(self) -> Iterator[Document]:
        with olefile.OleFileIO(self.file_path) as ole:
            if not self._is_valid_hwp(ole):
                raise ValueError(f"유효한 HWP 파일이 아닙니다: {self.file_path}")

            compressed = self._is_compressed(ole)
            sections = sorted(
                (item for item in ole.listdir() if item[0] == "BodyText"),
                key=lambda item: int(item[1][len("Section") :]),
            )

            for section_number, section_path in enumerate(sections):
                data = ole.openstream(section_path).read()
                if compressed:
                    data = zlib.decompress(data, -15)

                yield Document(
                    page_content=self._extract_text(data),
                    metadata={
                        "source": str(self.file_path),
                        "section": section_number,
                    },
                )


loader = HWPLoader("data/sample.hwp")
documents = loader.load()

print(f"섹션 수: {len(documents)}")
print(documents[0].page_content[:500])
```

</details>

## 4. CSVLoader, DataFrameLoader, 지연 로드

한 행을 하나의 `Document`로 변환하는 표 형식 데이터. CSV 파일은 `CSVLoader`, pandas 데이터프레임은 `DataFrameLoader` 사용.

<details markdown="1">
<summary>예시 코드: CSVLoader</summary>

```python
from langchain_community.document_loaders import CSVLoader

loader = CSVLoader(
    file_path="data/movies.csv",
    encoding="utf-8",
    csv_args={
        "delimiter": ",",
        "quotechar": '"',
    },
)
documents = loader.load()

print(documents[0].page_content)
print(documents[0].metadata)
```

</details>

<details markdown="1">
<summary>예시 코드: DataFrameLoader</summary>

```python
import pandas as pd
from langchain_community.document_loaders import DataFrameLoader

dataframe = pd.DataFrame(
    {
        "title": ["문서 로더", "텍스트 분할기", "임베딩"],
        "content": [
            "데이터를 Document 객체로 변환합니다.",
            "긴 문서를 작은 청크로 나눕니다.",
            "텍스트를 벡터로 변환합니다.",
        ],
    }
)

loader = DataFrameLoader(dataframe, page_content_column="content")
documents = loader.load()

for document in documents:
    print(document.page_content)
    print(document.metadata)
```

</details>

<details markdown="1">
<summary>예시 코드: 대용량 CSV 지연 로드</summary>

```python
from langchain_community.document_loaders import CSVLoader

loader = CSVLoader("data/large.csv", encoding="utf-8")

# 전체 목록 생성 없이 행 단위 처리
for index, document in enumerate(loader.lazy_load()):
    print(document.metadata, document.page_content[:100])

    # 처음 10개 행만 확인
    if index == 9:
        break
```

</details>

## 5. WebBaseLoader

HTML을 가져와 Beautiful Soup으로 텍스트를 추출하는 `WebBaseLoader`. 이용 약관과 `robots.txt` 확인 및 요청 빈도 제한 필요. JavaScript 기반 동적 콘텐츠는 별도 브라우저 로더 필요.

<details markdown="1">
<summary>예시 코드: 웹 페이지 불러오기</summary>

```python
from langchain_community.document_loaders import WebBaseLoader

loader = WebBaseLoader(
    web_paths=("https://python.langchain.com/docs/introduction/",),
    header_template={
        "User-Agent": "Mozilla/5.0 (compatible; LangChainTutorial/1.0)"
    },
)
documents = loader.load()

print(documents[0].page_content[:1000])
print(documents[0].metadata)
```

</details>

<details markdown="1">
<summary>예시 코드: 원하는 HTML 영역만 추출하기</summary>

```python
import bs4
from langchain_community.document_loaders import WebBaseLoader

loader = WebBaseLoader(
    web_paths=("https://example.com",),
    bs_kwargs={
        "parse_only": bs4.SoupStrainer(
            ["main", "article"],
        )
    },
)
documents = loader.load()

print(documents[0].page_content)
```

</details>

## 6. DirectoryLoader

glob 패턴으로 디렉터리 내 파일을 탐색하는 `DirectoryLoader`. 파일 형식별 `loader_cls` 지정. 하위 디렉터리는 `recursive=True`로 탐색.

<details markdown="1">
<summary>예시 코드: 디렉터리의 텍스트 파일 불러오기</summary>

```python
from langchain_community.document_loaders import DirectoryLoader, TextLoader

loader = DirectoryLoader(
    path="data/documents",
    glob="**/*.txt",
    loader_cls=TextLoader,
    loader_kwargs={"encoding": "utf-8"},
    recursive=True,
    show_progress=True,
    use_multithreading=True,
)
documents = loader.load()

print(f"문서 수: {len(documents)}")
print(documents[0].metadata)
```

</details>

<details markdown="1">
<summary>예시 코드: 디렉터리의 PDF 파일 불러오기</summary>

```python
from langchain_community.document_loaders import DirectoryLoader, PyPDFLoader

loader = DirectoryLoader(
    path="data/pdfs",
    glob="**/*.pdf",
    loader_cls=PyPDFLoader,
    recursive=True,
    silent_errors=True,
)

for document in loader.lazy_load():
    print(document.metadata.get("source"), document.metadata.get("page"))
```

</details>

## 8. LlamaParse, 멀티모달 모델로 파싱하기

### 8.1 LlamaParse

복잡한 PDF를 Markdown 또는 텍스트로 변환하는 API 기반 파서.

<details markdown="1">
<summary>예시 코드: LlamaParse로 PDF 파싱하기</summary>

```bash

parser = LlamaParse(result_type="markdown", language="ko")

documents = [

print(documents[0])
```

### 8.2 멀티모달 모델

문서 페이지의 표·차트·배치 등 시각 정보 분석용 멀티모달 모델. PDF 첫 페이지의 이미지 변환 및 모델 전달 예제.

<details markdown="1">
<summary>예시 코드: PDF 페이지를 멀티모달 모델로 분석하기</summary>

```bash
pip install -U langchain-openai pdf2image
```

```python
import base64
import io

from langchain_core.messages import HumanMessage
from langchain_openai import ChatOpenAI
from pdf2image import convert_from_path


def image_to_data_url(image) -> str:
    buffer = io.BytesIO()
    image.save(buffer, format="PNG")
    encoded = base64.b64encode(buffer.getvalue()).decode("utf-8")
    return f"data:image/png;base64,{encoded}"


# pdf2image 실행 조건: 시스템에 Poppler 설치
pages = convert_from_path(
    "data/chart-report.pdf",
    dpi=150,
    first_page=1,
    last_page=1,
)

model = ChatOpenAI(model="gpt-4.1-mini", temperature=0)
message = HumanMessage(
    content=[
        {
            "type": "text",
            "text": (
                "이 문서 페이지를 Markdown으로 변환하세요. "
                "제목과 문단의 계층을 유지하고, 표는 Markdown 표로 작성하며, "
                "차트의 핵심 수치와 추세를 설명하세요."
            ),
        },
        {
            "type": "image_url",
            "image_url": {"url": image_to_data_url(pages[0])},
        },
    ]
)

response = model.invoke([message])
print(response.content)
```

</details>

<details markdown="1">
<summary>예시 코드: 멀티모달 분석 결과를 Document로 저장하기</summary>

```python
from langchain_core.documents import Document

document = Document(
    page_content=response.content,
    metadata={
        "source": "data/chart-report.pdf",
        "page": 1,
        "parser": "multimodal-model",
    },
)

print(document.page_content[:1000])
print(document.metadata)
```

</details>

## 정리

| 데이터 원천 | 권장 로더/파서 | 특징 |
| --- | --- | --- |
| 일반 PDF | `PyPDFLoader` | 페이지 단위 텍스트 추출 |
| HWP | 사용자 정의 `HWPLoader` | HWP 5.x 본문 스트림 추출 |
| CSV | `CSVLoader` | 행 단위 문서 생성 |
| pandas DataFrame | `DataFrameLoader` | 지정 열을 본문으로 사용 |
| 웹 페이지 | `WebBaseLoader` | 정적 HTML 텍스트 추출 |
| 디렉터리 | `DirectoryLoader` | 여러 파일을 일괄 또는 지연 로드 |
| 복잡한 문서 | `UpstageDocumentParseLoader` | 레이아웃과 문서 요소 분석 |
| 복잡한 PDF | LlamaParse | Markdown 중심의 문서 파싱 |
| 표·차트·이미지 | 멀티모달 모델 | 시각 정보를 포함한 해석 |

대용량·다중 파일은 `lazy_load()` 권장. 검색 근거 추적을 위한 `metadata` 출처 정보 유지 필수.
