# 벡터 스토어(Vector Store) — 임베딩을 저장하고 유사한 문서를 검색하는 저장소

## 개념

**Vector Store**는 문서 Vector, 원문, metadata를 저장하고 질문과 가까운 문서를 검색합니다.

## 언제 사용하는가

- 많은 문서에서 의미적으로 가까운 Chunk를 빠르게 찾을 때
- metadata 조건으로 검색 범위를 제한할 때
- RAG 지식 베이스를 저장·갱신할 때

## 아키텍처

```text
Document + Embedding → Vector Store Index
질문 Vector ─────────> Similarity Search → 상위 K개 Document
```

## 핵심 원리

| 용어 | 의미 |
|---|---|
| Index | 가까운 Vector를 빠르게 찾는 자료 구조 |
| `k` | 반환할 후보 문서 수 |
| Filter | metadata로 검색 범위 제한 |
| Persistence | 재시작 후 데이터 유지 여부 |

`k`를 늘리면 정답 후보가 포함될 가능성과 잡음·비용이 함께 증가합니다.

## 바로 실행하는 코드

```bash
pip install -U langchain langchain-openai
```

`OPENAI_API_KEY` 환경 변수를 설정한 뒤 실행합니다.

```python
from langchain_core.documents import Document
from langchain_core.vectorstores import InMemoryVectorStore
from langchain_openai import OpenAIEmbeddings

docs = [
    Document(page_content="append는 리스트 끝에 값을 추가한다."),
    Document(page_content="pop은 리스트의 값을 제거한다."),
]
store = InMemoryVectorStore.from_documents(docs, OpenAIEmbeddings())

for doc in store.similarity_search("값을 추가하는 방법", k=1):
    print(doc.page_content)
```

## 요점 정리

1. 임베딩 모델은 Vector를 만들고 Vector Store는 저장·검색합니다.
2. 검색 결과는 보통 원문과 metadata를 가진 Document입니다.
3. `k`는 Recall과 잡음 사이의 균형값입니다.
4. 거리 점수의 범위와 방향은 저장소마다 확인합니다.
5. 운영 환경에서는 지속성·백업·권한·동시성을 함께 봅니다.
