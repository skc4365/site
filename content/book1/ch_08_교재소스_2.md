## 메모리 전략 선택

```text
같은 대화 안의 기록 → Checkpointer + thread_id
  ├─ 짧은 대화: 전체 메시지 유지
  ├─ 긴 대화: 최근 메시지 선택 또는 오래된 메시지 삭제
  └─ 매우 긴 대화: 과거 메시지를 요약해 상태에 저장

대화를 넘어 유지할 정보 → Store + user_id namespace
  ├─ 사용자·설비의 확정된 속성
  └─ 의미 검색이 필요한 장기 기억
```

## 기본 단기 메모리

```python
from langchain.agents import create_agent
from langgraph.checkpoint.memory import InMemorySaver

checkpointer = InMemorySaver()
agent = create_agent(
    model="openai:gpt-4.1-mini",
    tools=[],
    checkpointer=checkpointer,
)

config = {"configurable": {"thread_id": "inspection-001"}}

agent.invoke(
    {"messages": [{"role": "user", "content": "점검 설비는 프레스-01입니다."}]},
    config,
)
response = agent.invoke(
    {"messages": [{"role": "user", "content": "어느 설비를 점검 중인가요?"}]},
    config,
)
print(response["messages"][-1].content)
```

`thread_id`가 같으면 이전 상태를 이어가고, 다른 값을 사용하면 독립된 대화가 됩니다.

## SQLite 영속 메모리

프로세스가 종료되어도 대화를 유지해야 하는 로컬 실습에서는 SQLite Checkpointer를 사용합니다.

```python
import sqlite3
from langgraph.checkpoint.sqlite import SqliteSaver

connection = sqlite3.connect("checkpoints.sqlite", check_same_thread=False)
checkpointer = SqliteSaver(connection)

agent = create_agent(
    model="openai:gpt-4.1-mini",
    tools=[],
    checkpointer=checkpointer,
)
```

운영 환경에서는 동시성, 백업, 접근 제어를 고려해 PostgreSQL·Redis 등 영속 Checkpointer를 검토합니다.

## 긴 대화 관리 원칙

- 모델 호출 전에 메시지 수와 예상 토큰을 확인합니다.
- 최근 N개만 남길 때 시스템 메시지와 현재 작업에 필요한 정보는 보존합니다.
- 요약 결과에는 확정된 사실과 미해결 작업을 구분해 기록합니다.
- 원본 대화를 삭제하기 전에 감사·보존 정책을 확인합니다.
- 사용자별 장기 정보는 `thread_id`가 아니라 별도의 `user_id` namespace에 저장합니다.

## ZIP 노트북 실제 코드 셀

아래는 제공된 ZIP에서 직접 추출한 핵심 코드입니다. 원본 0.3 계열 코드이므로 먼저 구조를 읽고, 다음 절의 1.x 기준으로 수정합니다.

```python
from langchain_core.prompts import ChatPromptTemplate, MessagesPlaceholder
from langchain_community.chat_message_histories import ChatMessageHistory
from langchain_core.chat_history import BaseChatMessageHistory
from langchain_core.runnables.history import RunnableWithMessageHistory
from langchain_openai import ChatOpenAI
from langchain_core.output_parsers import StrOutputParser


# 프롬프트 정의
prompt = ChatPromptTemplate.from_messages(
    [
        (
            "system",
            "당신은 Question-Answering 챗봇입니다. 주어진 질문에 대한 답변을 제공해주세요.",
        ),
        # 대화기록용 key 인 chat_history 는 가급적 변경 없이 사용하세요!
        MessagesPlaceholder(variable_name="chat_history"),
        ("human", "#Question:\n{question}"),  # 사용자 입력을 변수로 사용
    ]
)

# llm 생성
llm = ChatOpenAI(model_name="gpt-4.1-mini")

# 일반 Chain 생성
chain = prompt | llm | StrOutputParser()

# --- 다음 원본 코드 셀 ---

chain_with_history = RunnableWithMessageHistory(
    chain,
    get_session_history,  # 세션 기록을 가져오는 함수
    input_messages_key="question",  # 사용자의 질문이 템플릿 변수에 들어갈 key
    history_messages_key="chat_history",  # 기록 메시지의 키
)

# --- 다음 원본 코드 셀 ---

chain_with_history.invoke(
    # 질문 입력
    {"question": "나의 이름은 테디입니다."},
    # 세션 ID 기준으로 대화를 기록합니다.
    config={"configurable": {"session_id": "abc123"}},
)

# --- 다음 원본 코드 셀 ---

chain_with_history.invoke(
    # 질문 입력
    {"question": "내 이름이 뭐라고?"},
    # 세션 ID 기준으로 대화를 기록합니다.
    config={"configurable": {"session_id": "abc123"}},
)

# --- 다음 원본 코드 셀 ---

chain_with_history.invoke(
    # 질문 입력
    {"question": "내 이름이 뭐라고?"},
    # 세션 ID 기준으로 대화를 기록합니다.
    config={"configurable": {"session_id": "abc1234"}},
)
```
