# 임베딩 실습

텍스트의 의미를 숫자 벡터로 변환하는 **임베딩(Embedding)**. 의미 검색, 문서 군집, 추천, 중복 탐지의 핵심 표현 방식.

## 핵심 개념

```text
문서 ──> 임베딩 모델 ──> 문서 벡터 ─┐
질문 ──> 같은 모델 ────> 질문 벡터 ─┴─> 유사도 비교
```

| 항목 | 핵심 |
| --- | --- |
| `embed_documents()` | 여러 문서의 벡터 생성 |
| `embed_query()` | 검색 질문의 벡터 생성 |
| 벡터 차원 | 모델이 반환하는 숫자 개수 |
| 유사도 | Cosine, Dot Product, Euclidean Distance 등 |
| 정규화 | 벡터 길이를 1로 맞추는 처리 |

- 동일한 인덱스에서 같은 임베딩 모델과 설정 사용
- 모델 또는 차원 변경 시 전체 문서 재임베딩
- 유사도는 의미적 근접성 지표이며 사실 여부의 판단 기준은 아님
- 실제 질문·문서 기반 검색 정확도 평가 필수
- 비용, 지연 시간, 데이터 전송 위치, 라이선스의 동시 검토

<details markdown="1">
<summary>예제 코드: Cosine Similarity 계산</summary>

```python
from math import sqrt


def cosine_similarity(vector_a: list[float], vector_b: list[float]) -> float:
    dot_product = sum(a * b for a, b in zip(vector_a, vector_b))
    norm_a = sqrt(sum(a * a for a in vector_a))
    norm_b = sqrt(sum(b * b for b in vector_b))
    return dot_product / (norm_a * norm_b)


query_vector = [1.0, 0.0, 1.0]
document_vector = [0.8, 0.1, 0.9]

score = cosine_similarity(query_vector, document_vector)
print(f"유사도: {score:.4f}")
```

</details>

## 1. OpenAIEmbeddings

OpenAI API를 이용하는 관리형 임베딩.

- 패키지: `langchain-openai`
- 인증: `OPENAI_API_KEY`
- 주요 모델: `text-embedding-3-small`, `text-embedding-3-large`
- 장점: 간단한 운영, 배치 처리, 안정적인 품질
- 고려 사항: API 비용, 네트워크 지연, 외부 데이터 전송
- `text-embedding-3` 계열: `dimensions` 옵션으로 출력 차원 조정 가능

<details markdown="1">
<summary>예제 코드: OpenAI 문서·질의 임베딩</summary>

```bash
pip install -U langchain-openai
```

환경변수 설정:

```bash
# macOS/Linux
export OPENAI_API_KEY="발급받은_API_키"

# Windows PowerShell
$env:OPENAI_API_KEY="발급받은_API_키"
```

```python
from langchain_openai import OpenAIEmbeddings

embeddings = OpenAIEmbeddings(
    model="text-embedding-3-small",
    dimensions=1024,
)

documents = [
    "모터의 진동이 기준값보다 증가했습니다.",
    "윤활유 교체 주기는 6개월입니다.",
    "프레스 설비의 온도가 정상 범위를 초과했습니다.",
]
query = "설비에서 진동 이상이 발생했습니다."

document_vectors = embeddings.embed_documents(documents)
query_vector = embeddings.embed_query(query)

print(f"문서 수: {len(document_vectors)}")
print(f"벡터 차원: {len(query_vector)}")
print(f"벡터 일부: {query_vector[:5]}")
```

비동기 처리:

```python
document_vectors = await embeddings.aembed_documents(documents)
query_vector = await embeddings.aembed_query(query)
```

</details>

## 2. CacheBackedEmbeddings

생성된 임베딩을 저장해 동일 텍스트의 중복 계산을 줄이는 래퍼.

- 목적: API 비용과 처리 시간 절감
- 저장 단위: 텍스트 해시와 임베딩 벡터
- 문서 캐시: `document_embedding_cache`
- 질의 캐시: `query_embedding_cache=True`
- 네임스페이스: 모델·버전·차원별 캐시 충돌 방지
- 주의: 모델 설정 변경 시 새 네임스페이스 또는 캐시 재구축

<details markdown="1">
<summary>예제 코드: 로컬 파일 기반 임베딩 캐시</summary>

```bash
pip install -U langchain-classic langchain-openai
```

```python
from time import perf_counter

from langchain_classic.embeddings import CacheBackedEmbeddings
from langchain_classic.storage import LocalFileStore
from langchain_openai import OpenAIEmbeddings

underlying = OpenAIEmbeddings(
    model="text-embedding-3-small",
    dimensions=1024,
)
store = LocalFileStore("./.cache/embeddings")

cached_embeddings = CacheBackedEmbeddings.from_bytes_store(
    underlying,
    store,
    namespace="text-embedding-3-small-1024",
    query_embedding_cache=True,
    batch_size=32,
)

texts = [
    "베어링 온도가 상승했습니다.",
    "모터 진동이 정상 범위를 벗어났습니다.",
]

start = perf_counter()
first_vectors = cached_embeddings.embed_documents(texts)
first_elapsed = perf_counter() - start

start = perf_counter()
second_vectors = cached_embeddings.embed_documents(texts)
second_elapsed = perf_counter() - start

print(f"첫 실행: {first_elapsed:.3f}초")
print(f"캐시 실행: {second_elapsed:.3f}초")
print(first_vectors == second_vectors)
```

질의 캐시 확인:

```python
first_query = cached_embeddings.embed_query("진동 이상")
second_query = cached_embeddings.embed_query("진동 이상")

print(first_query == second_query)
```

</details>

## 3. HuggingFaceEmbeddings

Sentence Transformers 모델을 로컬 프로세스에서 실행하는 임베딩.

- 패키지: `langchain-huggingface`
- 실행 위치: 로컬 CPU 또는 GPU
- 장점: 데이터 외부 전송 없음, 다양한 공개 모델
- 고려 사항: 모델 다운로드, 메모리 사용량, 추론 속도, 라이선스
- 모델 선택: 한국어 지원, 검색용 학습 여부, 벡터 차원, 최대 입력 길이 확인
- 정규화: `normalize_embeddings=True` 설정 시 Dot Product와 Cosine 유사도 일치

<details markdown="1">
<summary>예제 코드: 다국어 모델의 로컬 임베딩</summary>

```bash
pip install -U langchain-huggingface sentence-transformers
```

```python
from langchain_huggingface import HuggingFaceEmbeddings

embeddings = HuggingFaceEmbeddings(
    model_name="sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2",
    model_kwargs={"device": "cpu"},
    encode_kwargs={
        "normalize_embeddings": True,
        "batch_size": 32,
    },
)

documents = [
    "펌프 압력이 정상 범위입니다.",
    "모터에서 비정상 진동이 감지되었습니다.",
    "냉각수 온도가 빠르게 상승합니다.",
]
query = "설비 진동에 문제가 있습니다."

document_vectors = embeddings.embed_documents(documents)
query_vector = embeddings.embed_query(query)

scores = [
    sum(query_value * document_value for query_value, document_value in zip(
        query_vector,
        document_vector,
    ))
    for document_vector in document_vectors
]

for text, score in sorted(
    zip(documents, scores),
    key=lambda item: item[1],
    reverse=True,
):
    print(f"{score:.4f} | {text}")
```

GPU 사용 시 `model_kwargs={"device": "cuda"}`. 최초 실행 시 모델 파일 다운로드.

</details>

## 4. UpstageEmbeddings

Upstage API를 이용하는 관리형 임베딩.

- 패키지: `langchain-upstage`
- 인증: `UPSTAGE_API_KEY`
- 모델: `solar-embedding-1-large`
- 장점: 간단한 API 연동, 한국어 포함 다국어 검색 활용
- 고려 사항: API 비용, 네트워크 지연, 외부 데이터 전송
- 지원 방식: 동기 및 비동기 문서·질의 임베딩

<details markdown="1">
<summary>예제 코드: Upstage 문서·질의 임베딩</summary>

```bash
pip install -U langchain-upstage
```

환경변수 설정:

```bash
# macOS/Linux
export UPSTAGE_API_KEY="발급받은_API_키"

# Windows PowerShell
$env:UPSTAGE_API_KEY="발급받은_API_키"
```

```python
from langchain_upstage import UpstageEmbeddings

embeddings = UpstageEmbeddings(
    model="solar-embedding-1-large",
)

documents = [
    "압축기 토출 압력이 증가했습니다.",
    "생산 라인의 전력 사용량이 감소했습니다.",
]
query = "압축기 압력 이상"

document_vectors = embeddings.embed_documents(documents)
query_vector = embeddings.embed_query(query)

print(f"문서 벡터 수: {len(document_vectors)}")
print(f"질의 벡터 차원: {len(query_vector)}")
```

비동기 처리:

```python
document_vectors = await embeddings.aembed_documents(documents)
query_vector = await embeddings.aembed_query(query)
```

</details>

## 5. OllamaEmbeddings

로컬 Ollama 서버에서 실행하는 임베딩.

- 패키지: `langchain-ollama`
- 실행 위치: 로컬 PC 또는 사내 서버
- 인증: 기본 로컬 구성에서는 API 키 불필요
- 장점: 데이터 통제, 오프라인 환경, API 호출 비용 없음
- 고려 사항: 모델 다운로드, 서버 운영, CPU·GPU 자원, 처리 속도
- 조건: Ollama 서버 실행 및 임베딩 모델 사전 다운로드

<details markdown="1">
<summary>예제 코드: Ollama 로컬 임베딩</summary>

```bash
pip install -U langchain-ollama
ollama pull nomic-embed-text
```

```python
from langchain_ollama import OllamaEmbeddings

embeddings = OllamaEmbeddings(
    model="nomic-embed-text",
    base_url="http://localhost:11434",
)

documents = [
    "컨베이어 벨트의 정렬 상태를 확인합니다.",
    "베어링의 윤활 상태를 점검합니다.",
]
query = "윤활 점검 방법"

document_vectors = embeddings.embed_documents(documents)
query_vector = embeddings.embed_query(query)

print(f"문서 벡터 수: {len(document_vectors)}")
print(f"벡터 차원: {len(query_vector)}")
```

연결 확인:

```bash
ollama list
curl http://localhost:11434/api/tags
```

</details>

## 임베딩 선택 가이드

| 방식 | 실행 위치 | 주요 장점 | 주요 고려 사항 |
| --- | --- | --- | --- |
| `OpenAIEmbeddings` | OpenAI API | 간단한 운영, 관리형 품질 | 비용, 외부 전송 |
| `CacheBackedEmbeddings` | 선택한 저장소 | 중복 계산과 비용 감소 | 캐시 무효화 정책 |
| `HuggingFaceEmbeddings` | 로컬 CPU·GPU | 모델 선택 폭, 데이터 통제 | 자원, 속도, 라이선스 |
| `UpstageEmbeddings` | Upstage API | 한국어 활용, 간단한 연동 | 비용, 외부 전송 |
| `OllamaEmbeddings` | 로컬·사내 서버 | 오프라인 실행, 데이터 통제 | 서버와 모델 운영 |

## 최종 점검

- 문서와 질문의 동일 모델·버전·차원 사용
- 실제 한국어·도메인 질문 기반 검색 평가
- 모델 변경 시 벡터 인덱스 전체 재구축
- 배치 크기와 동시 요청 수 조정
- API 비용과 로컬 하드웨어 비용 비교
- 개인정보·기밀정보의 외부 전송 정책 확인
- 모델 이름과 설정을 메타데이터로 기록
