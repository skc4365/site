## 검토 결과

기존 문서는 Pydantic 파서만 포함합니다. 실제 응답 형태에 따라 목록·JSON·열거형·날짜 파서가 필요하고, 자동 수정 파서는 실패 처리 전략을 설명하는 심화 예제로 가치가 있습니다.

## 원본 예제 지도

| 번호 | 파서 | 반영 | 용도 |
| --- | --- | --- | --- |
| 01 | Pydantic | 필수 | 타입과 필드 검증 |
| 02 | CommaSeparatedList | 필수 | 간단한 문자열 목록 |
| 03 | Structured | 참고 | 고정된 필드 구조 |
| 04 | JSON | 필수 | JSON 객체 출력 |
| 05 | PandasDataFrame | 선택 | 표 질의 결과 해석 |
| 06 | Datetime | 선택 | 날짜·시간 형식 제한 |
| 07 | Enum | 필수 | 허용된 값만 선택 |
| 08 | OutputFixing | 심화 | 잘못된 결과의 재구성 |

## 1. Pydantic 구조화 출력

```python
from pydantic import BaseModel, Field
from langchain_openai import ChatOpenAI


class InspectionResult(BaseModel):
    machine_id: str = Field(description="설비 식별자")
    risk_level: str = Field(description="normal, warning, critical 중 하나")
    action: str = Field(description="권장 조치")


model = ChatOpenAI(model="gpt-4.1-mini", temperature=0)
structured_model = model.with_structured_output(InspectionResult)
result = structured_model.invoke("프레스-01의 진동이 평소보다 30% 증가했습니다.")
print(result.model_dump())
```

## 2. 간단한 목록 파서

```python
from langchain_core.output_parsers import CommaSeparatedListOutputParser

parser = CommaSeparatedListOutputParser()
print(parser.parse("온도 확인, 윤활 상태 확인, 진동 센서 점검"))
```

## 3. Enum으로 허용값 제한

```python
from enum import Enum
from langchain.output_parsers import EnumOutputParser


class RiskLevel(Enum):
    NORMAL = "normal"
    WARNING = "warning"
    CRITICAL = "critical"


parser = EnumOutputParser(enum=RiskLevel)
print(parser.parse("warning"))
```

## 사용 원칙

- 새 코드에서는 모델의 native structured output을 우선 검토합니다.
- 파싱 실패를 정상 결과로 위장하지 말고 재시도 횟수를 제한합니다.
- 업무 규칙 검증은 파서와 별도의 서비스 계층에서도 수행합니다.
- 자유 문장은 문자열 파서, 시스템 간 전달 데이터는 Pydantic 모델을 권장합니다.
