# 다양한 모델을 활용한 챗봇

## 먼저 보는 구조

```text
모델 선택 → 공통 invoke → 응답
```

## 핵심 개념

- 공급자별 패키지
- 모델 선택 UI
- 동일한 메시지 계약

## 기본 코드

```python
models = {'openai': openai_model, 'local': ollama_model}
response = models[selected_model].invoke(question)
```

## 코드 읽기

1. 입력이 무엇인지 찾습니다.
2. 어떤 객체가 실제 작업을 수행하는지 확인합니다.
3. 반환값의 타입과 내용을 출력합니다.
4. 작은 입력으로 먼저 실행합니다.

## 확인하기

- 이 코드의 입력과 출력은 무엇인가요?
- 실패할 수 있는 지점은 어디인가요?
- 결과를 확인하려면 무엇을 출력해야 하나요?
