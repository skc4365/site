# 리트리버(Retriever) — 질문을 받아 관련 Document를 반환하는 검색 인터페이스

## 개념

**Retriever**는 문자열 질문을 입력받아 관련 `Document` 목록을 반환하는 공통 검색 계약입니다.

```text
query: str → Retriever → list[Document]
```

## 언제 사용하는가

- Vector Store를 RAG Chain과 연결할 때
- 키워드·웹·DB 검색을 같은 방식으로 호출할 때
- 검색 전략을 생성 단계와 독립적으로 교체할 때

## 아키텍처

```text
질문 → 질의 처리 → Retriever → 후보 검색·필터 → Document 목록
```

## 핵심 원리

Retriever는 문서를 저장할 필요가 없고 답변도 생성하지 않습니다.

| 전략 | 특징 |
|---|---|
| Similarity | 질문과 가장 가까운 문서 우선 |
| MMR | 관련성과 결과 다양성을 함께 고려 |
| Filter | 기간·부서·권한 등 metadata 제한 |
| Rerank | 후보를 더 정교한 모델로 재정렬 |

## 바로 실행하는 코드

```bash
pip install -U langchain langchain-openai
```

`OPENAI_API_KEY` 환경 변수를 설정한 뒤 실행합니다.

```python
from langchain_core.documents import Document
from langchain_core.vectorstores import InMemoryVectorStore
from langchain_openai import OpenAIEmbeddings

docs = [
    Document(page_content="append는 리스트 끝에 값을 추가한다.", metadata={"topic": "추가"}),
    Document(page_content="extend는 여러 값을 리스트 끝에 추가한다.", metadata={"topic": "추가"}),
    Document(page_content="pop은 리스트에서 값을 제거한다.", metadata={"topic": "삭제"}),
]

store = InMemoryVectorStore.from_documents(
    docs,
    OpenAIEmbeddings(model="text-embedding-3-small"),
)
retriever = store.as_retriever(
    search_type="mmr",
    search_kwargs={"k": 2, "fetch_k": 3},
)
documents = retriever.invoke("리스트에 값을 추가하는 방법")

for document in documents:
    print(document.page_content, document.metadata)
```

## 요점 정리

1. Retriever의 입력은 질문, 출력은 Document 목록입니다.
2. Vector Store는 저장소이고 Retriever는 검색 계약입니다.
3. MMR은 비슷한 결과의 중복을 줄이는 데 사용합니다.
4. 권한 필터는 검색 전에 적용해야 합니다.
5. 검색 품질과 최종 답변 품질을 따로 평가합니다.
