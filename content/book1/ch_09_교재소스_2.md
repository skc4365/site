## 검토 결과

기존 문서는 PDF 로더 비교에 집중되어 있습니다. RAG 데이터 수집에는 표·문서·웹·폴더 단위 로딩도 필요하므로 형식별 선택 기준과 공통 검증 절차를 추가합니다.

## 원본 예제 지도

| 범주 | 원본 예제 | 반영 수준 |
| --- | --- | --- |
| PDF | 01 PDF Loader | 필수 |
| 사무 문서 | 02 HWP, 04 Excel, 05 Word, 06 PowerPoint | 필요 형식 선택 |
| 구조 데이터 | 03 CSV, 09 JSON | 필수 |
| 웹·논문 | 07 WebBase, 10 Arxiv | 선택 |
| 일반 텍스트 | 08 TXT | 필수 |
| 일괄 처리 | 11 Directory | 필수 |
| 레이아웃 분석 | 12 Upstage, 13 LlamaParser | 심화 |

## 공통 인터페이스

```python
from langchain_community.document_loaders import TextLoader

loader = TextLoader("data/manual.txt", encoding="utf-8")
documents = loader.load()

for document in documents[:2]:
    print(document.page_content[:100])
    print(document.metadata)
```

큰 파일이나 많은 파일은 한꺼번에 메모리에 올리지 않고 `lazy_load()`를 사용합니다.

```python
for document in loader.lazy_load():
    print(len(document.page_content), document.metadata)
```

## CSV와 JSON

```python
from langchain_community.document_loaders import CSVLoader, JSONLoader

csv_documents = CSVLoader("data/inspection.csv", encoding="utf-8").load()
json_documents = JSONLoader(
    file_path="data/alarms.json",
    jq_schema=".alarms[]",
    text_content=False,
).load()
```

## 폴더 일괄 로딩

```python
from langchain_community.document_loaders import DirectoryLoader, TextLoader

loader = DirectoryLoader(
    "data/manuals",
    glob="**/*.txt",
    loader_cls=TextLoader,
    loader_kwargs={"encoding": "utf-8"},
)
documents = loader.load()
```

## 로딩 후 필수 검증

- 문서 개수와 빈 문서 비율을 확인합니다.
- `source`, 페이지 번호, 시트 이름 등 출처 메타데이터를 보존합니다.
- 표와 이미지가 중요한 PDF는 텍스트 추출 결과를 원본 화면과 비교합니다.
- 암호화 파일, 손상 파일, 문자 인코딩 오류를 별도로 기록합니다.
- 외부 웹 문서는 이용 약관, 개인정보, 로봇 정책을 확인합니다.
