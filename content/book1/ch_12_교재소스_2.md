## 검토 결과

기존 문서는 Chroma만 포함합니다. 원본에는 FAISS와 Pinecone도 있으며, 로컬 실습·로컬 영속 저장·관리형 운영 환경을 구분하는 데 필요합니다.

## 원본 예제 지도

| 저장소 | 적합한 상황 | 주의점 |
| --- | --- | --- |
| Chroma | 로컬 실습과 간단한 영속 저장 | 운영 규모와 동시성 검토 |
| FAISS | 빠른 로컬 유사도 검색 | 메타데이터·영속화는 별도 설계 |
| Pinecone | 관리형 서비스와 확장 운영 | 비용, 리전, 외부 전송 정책 |

## 공통 벡터 저장소 흐름

```python
from langchain_core.documents import Document
from langchain_core.vectorstores import InMemoryVectorStore
from langchain_openai import OpenAIEmbeddings

documents = [
    Document(page_content="모터 진동이 증가하면 베어링을 점검합니다.", metadata={"id": "M-01"}),
    Document(page_content="온도가 80도를 넘으면 냉각 계통을 확인합니다.", metadata={"id": "M-02"}),
]

store = InMemoryVectorStore.from_documents(
    documents,
    OpenAIEmbeddings(model="text-embedding-3-small"),
)
results = store.similarity_search("진동 이상 조치", k=2)
print([(doc.metadata["id"], doc.page_content) for doc in results])
```

## 검색 옵션 확인

```python
retriever = store.as_retriever(
    search_type="mmr",
    search_kwargs={"k": 3, "fetch_k": 10},
)
documents = retriever.invoke("설비 이상 점검")
```

## 저장소 선택 기준

- 개발 단계에서는 InMemory·FAISS·Chroma처럼 설치가 단순한 저장소로 검증합니다.
- 운영 단계에서는 데이터 규모, 동시 사용자, 백업, 접근 제어, 관측 가능성을 확인합니다.
- 문서 ID와 원본 출처를 메타데이터에 저장해 갱신·삭제가 가능하게 합니다.
- 임베딩 모델명과 버전을 인덱스 메타데이터로 기록합니다.
- 벡터 저장소는 원본 문서 저장소의 대체물이 아니므로 원문도 별도로 보존합니다.
