# 프롬프트(Prompt) — 모델에 역할·문맥·출력 조건을 전달하는 입력 설계

## 개념

**프롬프트**는 모델에 수행할 작업과 사용할 정보를 전달하는 입력 계약입니다.

## 언제 사용하는가

- 모델의 역할과 답변 범위를 정할 때
- 사용자 질문과 검색 문서를 분리할 때
- 출력 길이·형식·금지 사항을 명확히 할 때

## 아키텍처

```text
역할 + Context + 작업 + 출력 형식 + 제한 조건 → Messages
```

## 핵심 원리

| 구성 | 역할 |
|---|---|
| System Message | 변하지 않는 행동 원칙 |
| Human Message | 현재 사용자 요청 |
| Input Variable | 실행할 때 바뀌는 값 |
| Few-shot | 입력과 기대 출력 예시 |

외부 문서는 명령이 아니라 참고 자료로 구분해야 합니다. 권한과 보안은 프롬프트만 믿지 말고 코드에서도 검사합니다.

## 바로 실행하는 코드

```bash
pip install -U langchain-core
```

```python
from langchain_core.prompts import ChatPromptTemplate

prompt = ChatPromptTemplate.from_messages(
    [
        ("system", "제공된 문서만 사용하고 두 문장 이내로 답하세요."),
        ("human", "문서:\n{context}\n\n질문: {question}"),
    ]
)

messages = prompt.invoke(
    {"context": "append()는 리스트 끝에 값을 추가한다.",
     "question": "리스트에 값을 추가하려면?"}
)
print(messages)
```

## 요점 정리

1. 프롬프트는 질문 문장이 아니라 재사용 가능한 입력 계약입니다.
2. 지속 규칙은 System, 현재 요청은 Human Message에 둡니다.
3. 질문과 외부 Context를 다른 변수로 분리합니다.
4. 출력 조건은 길이·필드처럼 확인 가능하게 적습니다.
5. 보안과 권한은 코드 계층에서도 통제합니다.
