# LLM 기본 용어 — 모델의 입력·출력과 비용을 이해하는 기초

## 개념

**LLM**은 입력 메시지를 Token으로 처리하고 다음 Token을 예측해 응답을 생성하는 모델입니다.

```text
Messages → Tokens → Model → AIMessage
```

## 언제 사용하는가

- Prompt와 대화 기록을 설계할 때
- Context Window와 API 비용을 관리할 때
- 응답 본문과 metadata를 구분할 때

## 아키텍처

```text
System Message ─┐
Human Message ──┼─> Context → Chat Model → AIMessage
History ────────┘                    ├─ content
                                    └─ usage_metadata
```

## 핵심 용어

| 용어 | 의미 |
|---|---|
| Token | 모델이 텍스트를 처리하는 단위 |
| Context Window | 한 요청에서 처리할 입력·출력 범위 |
| System Message | 역할과 행동 원칙 |
| Human Message | 사용자 질문 |
| AIMessage | 모델이 반환하는 응답 객체 |
| Temperature | 출력 다양성에 영향을 주는 설정 |

Temperature가 0이어도 완전한 결정성을 보장하지 않으며, 값을 높인다고 지식이 증가하지 않습니다.

## 바로 실행하는 코드

```bash
pip install -U langchain-openai
```

`OPENAI_API_KEY` 환경 변수를 설정한 뒤 실행합니다.

```python
from langchain_openai import ChatOpenAI

model = ChatOpenAI(model="gpt-4.1-mini", temperature=0)
response = model.invoke(
    [
        ("system", "두 문장 이내로 설명하세요."),
        ("human", "RAG란 무엇인가요?"),
    ]
)

print(response.content)
print(response.usage_metadata)
```

## 요점 정리

1. Chat Model은 메시지를 입력받아 `AIMessage`를 반환합니다.
2. 글자 수와 Token 수는 같지 않습니다.
3. 대화 기록과 검색 문서도 Context Window를 사용합니다.
4. 답변 본문은 `content`, 사용량은 metadata에서 확인합니다.
5. 자연스러운 답변이 사실이라는 뜻은 아닙니다.
