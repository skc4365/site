# RAG 챗봇

## 먼저 보는 구조

```text
질문 → 대화 기억 + 문서 검색 → 답변 + 출처
```

## 핵심 개념

- 대화형 검색
- context 구성
- 답변과 출처 분리

## 기본 코드

```python
docs = retriever.invoke(question)
answer = rag_chain.invoke({'question': question, 'context': format_docs(docs)})
sources = [doc.metadata for doc in docs]
```

## 코드 읽기

1. 입력이 무엇인지 찾습니다.
2. 어떤 객체가 실제 작업을 수행하는지 확인합니다.
3. 반환값의 타입과 내용을 출력합니다.
4. 작은 입력으로 먼저 실행합니다.
