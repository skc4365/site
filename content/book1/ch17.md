# RAG 챗봇 — 대화 문맥과 문서 검색을 결합해 출처 있는 답변을 만드는 앱

## 개념

**RAG 챗봇**은 사용자의 대화 맥락을 유지하면서 관련 문서를 검색해 답변과 출처를 제공하는 애플리케이션입니다.

## 언제 사용하는가

- 매뉴얼·규정·교육 자료를 대화형으로 검색할 때
- 후속 질문이 이전 질문을 참조할 때
- 답변 근거를 사용자가 확인해야 할 때

## 아키텍처

```text
사용자 질문 + 대화 기록
        ↓ 질문 정리
     Retriever → 관련 Document
        ↓
Prompt(question + context) → LLM → 답변
        └─ Document.metadata ─────> 출처
```

## 핵심 원리

대화 기록 전체를 검색 질의로 사용하지 않습니다. 현재 질문이 “그 방법의 단점은?”처럼 불완전하면 이전 대화를 이용해 독립적인 검색 질문으로 바꿉니다.

```text
검색 실패: 정답 문서가 Top-K에 없음
생성 실패: 정답 문서는 있지만 답변이 근거를 따르지 않음
출처 실패: 답은 맞지만 metadata 연결이 틀림
```

## 바로 실행하는 코드

```bash
pip install -U langchain langchain-openai
```
별도 PDF나 Vector DB 서버는 필요없음.

```python
from langchain_core.documents import Document
from langchain_core.output_parsers import StrOutputParser
from langchain_core.prompts import ChatPromptTemplate
from langchain_core.vectorstores import InMemoryVectorStore
from langchain_openai import ChatOpenAI, OpenAIEmbeddings


# 1. 실습용 문서 준비
documents = [
    Document(
        page_content="연차 휴가는 그룹웨어에서 신청하고 팀장의 승인을 받습니다.",
        metadata={"source": "인사규정", "page": 3},
    ),
    Document(
        page_content="비밀번호는 보안 포털의 계정 관리 메뉴에서 변경합니다.",
        metadata={"source": "보안지침", "page": 7},
    ),
]

# 2. 문서를 임베딩하여 메모리 Vector Store와 Retriever 생성
store = InMemoryVectorStore.from_documents(
    documents=documents,
    embedding=OpenAIEmbeddings(model="text-embedding-3-small"),
)
retriever = store.as_retriever(search_kwargs={"k": 1})

# 3. 질문 재작성 Chain과 답변 Chain 생성
model = ChatOpenAI(model="gpt-4.1-mini", temperature=0)

rewrite_prompt = ChatPromptTemplate.from_template(
    """대화 기록을 참고해 현재 질문을 독립적인 검색 질문으로 바꾸세요.
대화 기록: {history}
현재 질문: {question}
검색 질문만 출력하세요."""
)
rewrite_chain = rewrite_prompt | model | StrOutputParser()

answer_prompt = ChatPromptTemplate.from_template(
    """아래 문서만 사용해 질문에 답하세요.
문서에 답이 없으면 '문서에서 확인할 수 없습니다.'라고 답하세요.

문서: {context}
질문: {question}"""
)
answer_chain = answer_prompt | model | StrOutputParser()


def ask(question: str, history: list[str]) -> str:
    """후속 질문을 정리하고 문서를 검색해 출처와 함께 답합니다."""
    search_query = (
        rewrite_chain.invoke({"history": history, "question": question})
        if history
        else question
    )
    found = retriever.invoke(search_query)
    context = "\n\n".join(doc.page_content for doc in found)
    answer = answer_chain.invoke({"question": question, "context": context})

    print(f"검색 질문: {search_query}")
    print(f"답변: {answer}")
    print("출처:", [doc.metadata for doc in found])

    history.extend([f"사용자: {question}", f"AI: {answer}"])
    return answer


# 4. 첫 질문과 문맥이 필요한 후속 질문 실행
chat_history: list[str] = []
ask("연차 휴가는 어디에서 신청하나요?", chat_history)
ask("승인은 누가 하나요?", chat_history)
```

두 번째 질문의 검색어에는 첫 대화의 “연차 휴가” 문맥이 반영되어야 합니다. 실행 결과로 답변과 실제 검색 문서의 metadata가 함께 출력됩니다.

## 품질 확인

| 단계 | 확인할 것 |
|---|---|
| 질문 정리 | 원래 의도가 유지되는가 |
| 검색 | 정답 근거가 Top-K에 있는가 |
| 생성 | 답변 주장이 Context에 근거하는가 |
| 출처 | 실제 사용한 문서와 연결되는가 |

## 요점 정리

1. RAG 챗봇은 대화 상태·검색·생성을 결합합니다.
2. 후속 질문은 검색 가능한 독립 질문으로 정리합니다.
3. 검색 결과와 생성 답변을 따로 평가합니다.
4. 문서에 근거가 없으면 모른다고 답하도록 설계합니다.
5. 출처는 검색된 Document metadata에서 만듭니다.
