## 1. 기본 문자열 프롬프트

```python
from langchain_core.prompts import PromptTemplate

prompt = PromptTemplate.from_template(
    "다음 설비 경고를 작업자가 이해하기 쉽게 설명하세요.\n경고: {warning}"
)
print(prompt.invoke({"warning": "모터 온도 85°C"}).to_string())
```

## 2. 대화형 프롬프트

```python
from langchain_core.prompts import ChatPromptTemplate

prompt = ChatPromptTemplate.from_messages(
    [
        ("system", "당신은 제조 설비 점검 도우미입니다."),
        ("human", "설비: {machine}\n증상: {symptom}"),
    ]
)
messages = prompt.invoke({"machine": "프레스-01", "symptom": "진동 증가"})
print(messages.to_messages())
```

## 3. Few-shot 프롬프트

```python
from langchain_core.prompts import FewShotPromptTemplate, PromptTemplate

examples = [
    {"warning": "온도 상승", "level": "주의"},
    {"warning": "비상 정지", "level": "긴급"},
]
example_prompt = PromptTemplate.from_template("경고: {warning} → 등급: {level}")
prompt = FewShotPromptTemplate(
    examples=examples,
    example_prompt=example_prompt,
    suffix="경고: {warning} → 등급:",
    input_variables=["warning"],
)
print(prompt.invoke({"warning": "윤활유 부족"}).to_string())
```

## 선택 기준

- 한 문장 입력은 `PromptTemplate`로 시작합니다.
- 역할과 메시지 순서가 중요하면 `ChatPromptTemplate`을 사용합니다.
- 출력 패턴을 예시로 가르쳐야 하면 Few-shot을 사용합니다.
- 외부 Hub 프롬프트는 내용을 검토하고 버전을 고정한 뒤 사용합니다.
