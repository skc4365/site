### 이 코드에서 바꿀 부분

- 원본의 import 경로와 호출 API가 1.x에서도 유지되는지 장별 변환 코드와 비교합니다.

## Python 3.12·LangChain 1.x 적용

Python 3.12 가상환경에서 0.3 원본과 1.x 수업환경을 분리합니다.

```powershell
py -3.12 -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

## 원본을 읽는 순서

1. import와 초기 설정을 찾습니다.
2. 입력 데이터가 만들어지는 셀을 확인합니다.
3. 핵심 객체의 반환 타입을 출력합니다.
4. 위 1.x 패턴으로 바꾸고 작은 입력부터 실행합니다.

> ZIP 원본은 LangChain 0.3 계열 참고 자료이고, 수업 실행 기준은 Python 3.12·LangChain 1.x입니다.
